# スキル評価をエージェントで自動実行する

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

[スキル評価](../../agents/skills/skill-evaluation/SKILL.md)は評価を実施するAIまたは人が手で行う。修正前後のスキルを同じケースで実行して比較する作業を、コマンド1つでテストのように繰り返せるようにする。

## 要求

- 基準版（例: HEAD）と今回版（例: 作業ツリー）のスキルを、同じケースでエージェントのCLI（Claude Code・Codexなど）に実行させる。
- ケースごとに複数回実行し、採点結果と差分をレポートとして `03-output/skill-evaluation/` に保存する。
- 実行のたびにAPI料金がかかることと、実行回数の上限を手順に記載する。
- エージェントを呼ばずに評価機構だけを確認するテストを用意する。

## 完了条件

- [ ] 1コマンドで基準版と今回版の評価・比較ができる。
- [ ] 評価結果が既存の評価記録と同じ形式で保存される。
- [ ] エージェントを呼ばないテストがある。
