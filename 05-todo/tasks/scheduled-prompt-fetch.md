# プロンプトの取得・登録を定期実行する

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

[Claude・Codexからプロンプトを取得するスクリプト](fetch-ai-prompts.md)は手動実行のため、実行を忘れると記録が抜け、ナレッジ化や傾向分析の材料が欠ける。

## 要求

- 取得・登録を一定間隔（例: 6時間ごと）で自動実行する。
- 利用するOSに応じた登録方法（cron・launchd・systemd timerなど）と解除方法を手順にまとめる。
- 前回実行時刻を保存し、差分だけを取得する。保存先は追跡対象外にする。
- 実行ログの保存先と、失敗時の確認方法を決める。

## 完了条件

- [ ] 定期実行の登録・解除手順が `agents/skills/` に記載されている。
- [ ] 定期実行で新しいプロンプトだけが重複なく登録される。
