# TODOの期限・リマインドをOSのリマインダーに登録する

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

タスクファイルに期限やリマインドの日時を書いても、通知されないため見落とす。期限のあるタスクをOSのリマインダーへ登録し、期日に通知されるようにする。

## 要求

- タスクファイルに期限・リマインド日時を書く形式を決め、[タスク雛形](../../00-rules/templates/todo-task.md)に反映する。
- 期限のある未完了タスクをmacOSのリマインダーなどへ登録するスクリプトを作る。再実行しても重複登録しない。
- 登録前に内容を確認できる `--dry-run` を用意する。
- リマインダーアプリを操作しないテストを用意する。

## 完了条件

- [ ] 期限のあるタスクがリマインダーに重複なく登録される。
- [ ] 実行方法・依存ツール・変更対象が `scripts/README.md` に記載されている。
