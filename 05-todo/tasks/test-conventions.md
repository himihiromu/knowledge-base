# テストの配置・命名・一括実行方法を統一する

- 状態: 未着手
- 確認日: 2026-10-04
- 出典: 同日のリポジトリ調査。Node.jsの `scripts/test/*.test.mjs` と、`scripts/*-test.sh` の両方が存在し、配置・命名・実行方法が異なることを確認。

## 目的

テストを見つけやすくし、全体または対象別に同じ方法で実行できるようにする。

## 要求

- 言語やテスト対象が異なる場合の標準配置と命名を決める。
- 個別テストと全テストの実行方法、依存ツール、変更対象の有無を記録する標準を定義する。
- GitHub Actions等で実行する検査と、ローカル専用の検査の範囲を明確にする。
- 既存テストを新ルールに照合し、必要な移動やランナー整備を行う。

## 完了条件

- [ ] テスト配置・命名・実行方法がREADMEまたはルール文書に明記されている。
- [ ] 全テストを実行する単一の案内またはコマンドがある。
- [ ] CIで実行する検査の対象と実行方法が明記されている。
- [ ] 既存テストが規約に沿い、移動後の参照・CI設定が更新されている。

## 次の行動
