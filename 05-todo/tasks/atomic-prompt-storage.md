# プロンプト保存・登録処理のatomic化と排他制御

- 状態: 完了
- 完了日: 2026-10-04
- 確認日: 2026-10-12
- 出典: 2026-10-01のユーザー発言。保存失敗時の中途半端な状態、二重登録、並列書き込みを防ぐ依頼。

## 目的

保存・登録中の失敗や複数プロセスからの同時実行で記録が不整合にならないようにする。

## 要求

- 保存と集約の一時ファイル置換を行う。
- 再実行時の衝突と並列書き込みを制御する。
- 両スクリプトに適用し、障害・再実行・並列を確認する。

## 完了条件

- [x] 保存・登録両スクリプトに排他と失敗時の扱いがある。
- [x] 障害・再実行・並列のテストがある。
- [x] 利用上の制約が文書化されている。
