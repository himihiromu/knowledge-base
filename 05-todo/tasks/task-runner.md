# よく使う操作をタスクランナーにまとめる

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

スクリプトの実行方法・テストの実行方法がスクリプトごとに異なり、`scripts/README.md` を読まないと実行できない。よく使う操作を短いコマンドで実行できるようにする。

## 要求

- justなどのタスクランナーで、検査・テスト・プロンプト取得・スキル評価などをコマンドにまとめる。
- コマンド一覧を表示できるようにする。
- 依存ツールをそろえる開発環境（Nixなど）と合わせて導入するか検討する。

## 完了条件
