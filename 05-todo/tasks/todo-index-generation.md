# TODO一覧をタスクファイルから自動生成する

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

[TODO一覧](../README.md)は手で更新しており、タスクの追加・完了時に一覧の更新漏れや状態の食い違いが起きうる（[既存スキル文書とTODOの状態・記載を整合させる](skill-docs-and-status.md)）。

## 要求

- 各タスクファイルの状態・タイトルから、READMEの未完了・完了の一覧を生成するスクリプトを作る。
- 現在の一覧にある分類見出し（「ナレッジ運用」など）を保つため、タスクファイルに分類を書く欄を設けるか検討する。
- 一覧が最新でないときに失敗するチェックモードを用意し、pre-commitまたはCIで実行する。

## 完了条件

- [ ] スクリプトでREADMEの一覧が更新される。
- [ ] 一覧とタスクファイルの状態が食い違うときに検査が失敗する。

## 次の行動

- [ ] 手で書いている分類見出しを維持する方法を決める。
