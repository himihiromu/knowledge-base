# 作業日報の傾向分析・作成スキルを追加する

- 状態: 未着手
- 確認日: 2026-10-07
- 出典: 2026-10-07のユーザー依頼。社内で運用中のナレッジベースと比較し、こちらに無いスキル・機能をTODO化する依頼（Kiro対応とカレンダー取得は対象外と指示あり）。

## 目的

保存したプロンプト履歴やPRの記録から、その日の作業を日報としてまとめる作業を効率化する。過去の日報の書き方の傾向を分析し、それに沿った下書きを作る。

## 要求

- 過去の日報の原本を `04-materials/` に保存する形式を決める（提出先のシステムに依存しない形）。
- 原本から書き方の傾向（構成・粒度・表現）を分析し、`02-knowledge/` に整理するスキルを作る。
- 指定した日のプロンプト履歴・PRの記録と傾向から、日報の下書きを `03-output/` に作るスキルを作る。AIの作業だけで量が足りない日は利用者に聞いて補う。
- 確定版の日報を原本として取り込み、傾向分析に戻す流れを作る。

## 完了条件

- [ ] 傾向分析と下書き作成のスキルに、目的・使う場面・入力・手順・出力先・確認方法がある。
- [ ] 指定した日の作業から日報の下書きを作れることを確認した記録がある。

## 次の行動
