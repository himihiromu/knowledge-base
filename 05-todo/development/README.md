# 開発の依頼と進捗

このリポジトリを入口として、別リポジトリの開発タスクを管理する。

- 開発先情報: [repositories/](repositories/README.md)
- 開発タスク: ここに `<リポジトリ識別名>-<タスク名>.md` を作る。[開発タスクの雛形](../../00-rules/templates/development-task.md)を利用する。
- 整理した知見: [02-knowledge/development/](../../02-knowledge/development/README.md)
- 調査・検証の元記録: [04-materials/development/](../../04-materials/development/README.md)

実装は指定した開発先で行い、ここには依頼・進捗・成果物へのリンクを残す。実行前に開発先の作業パス・ブランチ・Git状態とAGENTS.md等の指示を確認する。未確認の操作権限は登録情報から推測しない。

## 使い方

1. リポジトリ情報の雛形を `repositories/<リポジトリ識別名>.md` へコピーし、URL・作業パス・ベースブランチ・開発先の指示・検証方法を記入する。
2. 開発タスクの雛形をこのディレクトリへコピーし、開発先情報へのリンク、要求と完了条件を記入する。
3. AIへ「この開発タスクに沿って、記載の開発先で実装・検証して」と依頼する。TAKTへ渡す場合は開発先を指定して登録し、作業先が正しいことを確認する。この案内の作成だけでは自動登録・実行は行われない。
4. 結果はタスクにPR・コミット・検証結果として残す。観測記録は04、整理・検証した知見は02へ保存し、相互にリンクする。
