# 開発先リポジトリ

開発先ごとに `<リポジトリ識別名>.md` を作り、[リポジトリ情報の雛形](../../../00-rules/templates/development-repository.md)に沿って記録する。

URL、用途、作業パス、ベースブランチ、開発・検証コマンド、開発先の指示ファイル、関連タスク・知見を記録する。確認できた情報だけを埋め、環境依存のパスには確認した環境を添える。非公開の情報は01内に保存し、認証情報は含めない。
