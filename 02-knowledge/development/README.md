# 開発の知見

開発で得た知見を整理・検証して保存する。リポジトリ固有の知見は `<リポジトリ識別名>/<テーマ>.md`、複数の開発先で再利用する知見は `common/<テーマ>.md` とする。最初のメモを保存するときに必要なディレクトリを作る。

[知識メモの雛形](../../00-rules/templates/note.md)を利用し、適用対象・成立条件・要点・確認日・出典・未検証事項を残す。出典は[開発の元記録](../../04-materials/development/README.md)、PR、コミット、公式資料等へリンクする。単発の観測や未整理のログは先に04へ置く。

対応する[開発先情報](../../05-todo/development/repositories/README.md)と[開発タスク](../../05-todo/development/README.md)から知見を参照できるようにする。非公開の知見は01内に保存する。

確認日: 2026-10-01。出典: 同日のユーザー発言。開発の知見をまとめる場所を作成する依頼。
