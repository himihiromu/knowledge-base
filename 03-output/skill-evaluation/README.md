# スキル評価の結果

スキル評価機構による評価結果ファイルを置く。
手順・雛形・命名規則の正は[スキル評価](../../agents/skills/skill-evaluation/SKILL.md)に一任する。

ここに置くのは、ケースに基づいて人が採点したスキル成果と、その理由・未検証範囲・比較結果である。スキル文書のリンクなどを検査する機械テストはここに置かず、評価結果としても扱わない。ケースとサンプルの配置は、手順書の[配置とリンク](../../agents/skills/skill-evaluation/SKILL.md#配置とリンク)に従う。

結果ファイルは修正前後の比較の前提になるため、保存後に編集しない。
