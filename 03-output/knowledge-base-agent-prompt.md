# OpenClaw・Hermes Agent向けナレッジベース更新プロンプト

- 作成日: 2026-09-29
- 用途: Discordでエージェントに渡す初期指示
- 状態: 利用可能。参照するファイルをGitHubへ反映してから送信する。
- 根拠: [共通指示](../agents.md)、[運用ルール](../00-rules/workflow.md)、2026-09-29の会話での複数エージェント・PR運用の相談。

以下の枠内をコピーして送信する。

```text
今後、私との会話・調査・作業から得た再利用可能な情報を、次のナレッジベースに蓄積してください。
https://github.com/himihiromu/knowledge-base

【最初に】
リポジトリのデフォルトブランチにある agents.md（小文字）、README.md、00-rules/workflow.md を読んでください。取得できない場合は、推測で進めず、読めなかったファイルを報告してください。
利用環境で継続指示を保存できる場合は、この依頼とリポジトリの参照先を保存してください。次回以降も実行できるか、実際に設定した内容を報告してください。

【日常の更新】
関連する相談や作業の前に既存の知識を検索し、回答に活用してください。作業の区切りで、新しい学び・決定事項・解決手順・タスクを保存してください。雑談や既存情報の言い換えだけなら、更新は不要です。
04-materials は資料・会話の記録（ブロンズ）、02-knowledge は整理・検証した知識（シルバー）、03-output は成果物（ゴールド）です。元資料を残し、04 → 02 → 03 の参照リンクを付けてください。タスクと進捗は05-todoに保存してください。
関連する手順はagents/skills、機械的な処理はscriptsを確認してください。
出典・確認日を記録し、私の発言、資料の内容、あなたの推測を区別してください。既存メモとの重複や矛盾を確認し、本文未取得の資料を読んだことにしないでください。
個人情報・非公開情報は01-secretで扱い、GitやPR、Discordの報告へ転載しないでください。01・06・99の実体はGit対象外です。不要なファイルの退避は運用ルールに従ってください。

【複数エージェントでのGit運用】
この依頼では、ナレッジベース更新のための作業ブランチへのコミット・push・PR作成を許可します。
作業開始時に最新のデフォルトブランチと既存PRを確認し、専用のcloneまたはworktreeで作業してください。ブランチ名は kb/<エージェント名>/<日時>-<テーマ> など、他の作業と重複しない名前にしてください。
1つの調査や整理など、意味のある作業単位でPRを作成してください。同じ作業の追加修正は自分の既存PRにまとめてください。
mainなどの共有ブランチへ直接pushせず、他のエージェントのブランチを変更しないでください。force pushとPRのマージは行わず、マージは私に任せてください。
PR作成前に差分、リンク、機密情報の混入を確認し、PR本文に変更内容・出典・確認結果・未確認事項を記載してください。

【実行できない場合と報告】
Web閲覧だけでは更新できません。clone・編集・push・PR作成に必要な機能や認証がなければ、不足しているものを具体的に報告してください。認証情報そのものをDiscordに送るよう求めないでください。
更新後は変更の要点とPRのURLを簡潔に知らせてください。PR作成前の変更を共有ナレッジへ反映済みとは扱わないでください。
まずはルールの理解と実行環境を確認し、更新できる状態か報告してください。この初回確認だけで内容のないPRや定期ジョブを作る必要はありません。
```
