# スクリプト

構造検査、リンク検査、形式変換など、機械的に実施したほうがよいタスクのコードを置く。
スクリプトを追加するときは、目的・実行方法・依存ツール・変更対象をここに記録する。
作業全体の判断や手順は[agents/skills](../agents/skills/README.md)にまとめる。

## save-ai-prompt.sh — AIとのプロンプトの保存

### 目的と役割分担

AI作業への指摘（プロンプト原文）を1件1ファイルで `04-materials/prompts/` へ記録し、そこから抜き出した好み・方針を `02-knowledge/ai-work-preferences.md` へ出典リンク付きで追記する。

- 指摘のどこが好み・方針かを抜き出す判断は、呼び出し側（人間またはAI）が行い、`--takeaway` として渡す。
- スクリプトは判断をせず、受け取った内容を決められた形式で機械的に保存する。

### 実行方法

```console
scripts/save-ai-prompt.sh --title "タイトル" --takeaway "抜き出した方針" [--takeaway "方針2"] [--date YYYY-MM-DD] [--file 本文ファイル] [--root 出力ルート]
```

- 本文は `--file` で渡すか、`--file` を省いたときは標準入力から読む。
- `--date` を省くと当日日付（`date +%F`）を使う。
- `--root` を省くと、このスクリプトの位置からリポジトリのルートを導出する。確認スイートは一時ディレクトリを渡す。

### 依存ツール

bash、GNU coreutils（`date`、`tr`、`dirname`、`mkdir`、`mktemp`、`cat`、`mv`、`rm`）、sed、grep。

### 入力

| 引数 | 必須 | 内容 |
|------|------|------|
| `--title` | 必須（1回） | 記録のタイトル。出力ファイル名の一部になる |
| `--takeaway` | 必須（1件以上） | 指摘から抜き出した方針。繰り返し指定できる |
| `--date` | 省略可 | `YYYY-MM-DD` 形式 |
| `--file` | 省略可 | 本文のファイル。省略時は標準入力 |
| `--root` | 省略可 | 出力ルート。省略時はスクリプト位置から導出 |

### 出力（変更対象）

| 出力先 | 内容 |
|--------|------|
| `04-materials/prompts/YYYY-MM-DD-タイトル.md` | 指摘原文の記録。1実行につき1ファイルを新規作成する |
| `02-knowledge/ai-work-preferences.md` | 方針の集約。初回の保存でヘッダを作り、以後はエントリを追記するのみ |

### 保存形式

記録ファイルは、front matter（見出し・確認日・出典・抽出した方針）の後に `## 本文` 見出しを置き、その後ろからEOFまで本文を逐語で保存する。

```markdown
# YYYY-MM-DD タイトル

- 確認日: YYYY-MM-DD
- 出典: YYYY-MM-DDのAI作業中の指摘

## 抽出した方針

- 方針1
- 方針2

## 本文

（`## 本文` の空行の後ろから、渡された本文を1バイトも変えずにそのまま保存する）
```

- 本文は変換しない。コードフェンスで囲まず、エスケープせず、行の整形・除去をしない。末尾改行の有無も入力どおり。
- タイトルと方針だけは1行として扱い、埋め込み改行を空白へ置換する。
- ファイル名のタイトル部分は、空白・`/`・`\`・制御文字を `-` へ置換し、連続する `-` を1つへ圧縮し、先頭末尾の `-` と `.` を除いて正規化する。日本語など非ASCII文字は保持する。
- 集約のエントリは、`## 日付 タイトル` の見出し、方針の箇条書き、`../04-materials/prompts/` への出典リンクの順で追記する。

### 失敗時の挙動

- タイトル・方針・本文の不足、日付形式の不正、`--file` の不在、同じ日付とタイトルの記録が既にある場合は、使い方を標準エラーへ出して非ゼロで終了する。
- 入力検証エラー・既存記録との衝突時は、既存の記録と集約を変更せず、新しい記録ファイルも残さない。
- 記録の保存と集約への追記は順番に行う。集約先の権限不足や容量不足などで追記が失敗した場合、記録ファイルだけが残ることがある。再実行前に保存結果を確認する。
- 同時実行の排他制御は行わない。同じ出力ルートへの保存は1件ずつ実行する。

## save-ai-prompt-test.sh — 保存スクリプトの確認

### 目的

save-ai-prompt.sh の正常系と、データを壊さない異常系（衝突拒否・入力不足・逐語保存・集約の追記保持）を確認するスイート。フレームワークを使わず bash だけで動く。

### 実行方法

```console
bash scripts/save-ai-prompt-test.sh
```

合否は最後の `結果: N 成功 / M 失敗` 行と終了コード（成功 0、失敗 1）で読む。

### 依存ツール

bash、GNU coreutils（`mktemp`、`mkdir`、`rm`、`sha256sum`、`wc`、`cp`、`tail`、`head`）、diffutils（`cmp`）、grep、findutils（`find`）、sed。

### 変更対象

なし。`--root` に `mktemp` の一時ディレクトリを渡すため、リポジトリの実物は書き換えない。一時ディレクトリは終了時に削除する。

## check-knowledge-diff.mjs

- 目的: commit前に、ステージ済み差分（`git diff --cached`）の本文へ混ざった日付・時刻・経緯を示唆する語を検出して報告する。検出手順と候補の判定は[commit前ナレッジ検査](../agents/skills/validate-committed-knowledge/SKILL.md)に従う。
- 実行方法: `node scripts/check-knowledge-diff.mjs [パス...]`。引数で差分のパスを絞り込める。`01-secret/`・`06-storage/`・`99-trash/`・`.takt/` 配下は常に除外する。終了コードは 0=検出なし、1=検出あり、2=実行環境エラー。
- 依存ツール: Node.js、git。外部パッケージは使わない。読み取り専用で、ファイル・作業ツリー・ステージを変更しない。
- 変更対象: なし（標準出力と標準エラー出力への報告のみ）。テストは `node --test scripts/test/check-knowledge-diff.test.mjs`。
