# 保存済みプロンプトから知識を整理する

## 目的

保存済みプロンプトを精査し、出典を確かめたうえで、単発の記録として保留するか、繰り返し確認された知識として整理するかを判断する。原文と整理した知識の関係を追えるようにする。

## 使う場面

- `04-materials/prompts/` に保存されたプロンプトを見直すとき。
- 保存済みプロンプトから、再利用できる判断基準や技術的な知識を整理するとき。

## 入力

- 精査する保存済みプロンプトの原文とファイルパス。
- 原文に記録された出典と確認日。記録がない場合は、その欠落を確認する。
- 同じ分類または対象について過去に確認された記録と、必要に応じて確認できる根拠資料。

## 手順

知識化の判断では、以下の段階を順に確認する。

1. **原文を精査する**: 保存済みプロンプトを省略せず読み、要求、指摘、事実の主張、提案を区別する。文脈や根拠資料を確認できない主張は、確認済みの事実として扱わない。
2. **出典を確認する**: 原文の保存先、出典、確認日を確認する。原文の主張を裏付ける資料がある場合はその資料も確認する。資料本文を確認できない場合は、内容を推測せず未確認と記録する。
3. **機密性を確認する**: 原文に機密情報が含まれる場合、その内容を通常の知識領域へ複写しない。保存先はリポジトリの機密情報ルールに従い、`01-secret/` に隔離する。機密区分の指定が必要な保存は、スクリプトの責務に従って呼び出し側が判断する。
4. **ライフサイクルを判断する**: [知識ライフサイクルの判断手順](../knowledge-lifecycle/SKILL.md)に従う。1件の指摘・気づきは observation として扱い、同じ分類または対象について2件以上あり、傾向分析で繰り返しが確認できるまでは knowledge へ昇格しない。頻度や回数だけで rule に昇格しない。rule にするのは、ユーザーが常時守らせたい意図を明示した場合に限る。分類単位や昇格条件を独自に追加しない。
5. **知識を整理する**: knowledge にできると確認した内容だけを [02-knowledge](../../../02-knowledge/README.md) の配置ルールと知識メモの雛形に従って整理する。事実、推測、未検証事項を分け、未検証の主張には未検証であることを記す。単発の内容は observation として適切な記録先に保留する。
6. **原文への出典リンクを付ける**: 整理した知識から元のプロンプトへたどれる Markdown 出典リンクを記録する。プロンプト原文は [保存済みプロンプト](../../../04-materials/prompts/README.md) の配置に従って参照し、ファイルへのリンクが解決することを確認する。原文を確認できない、または参照先が特定できない場合は、リンクを推測で作らず未確認として残す。
7. **保存処理を分担する**: [スクリプトの案内](../../../scripts/README.md)を参照する。保存前に機密性を判断し、機密情報を含む原文は単発か繰り返し確認後かにかかわらず `register-ai-prompt.sh --secret` で `01-secret/prompts/` に隔離する。1件だけで繰り返しの傾向が確認できていない段階では原文を observation として登録し、`save-ai-prompt.sh` による knowledge への追記は行わない。同じ分類または対象について2件以上あり、傾向分析で繰り返しが確認できた後に knowledge へ整理する場合は、`save-ai-prompt.sh` を利用できる。ただし、機密情報を含む原文や機密情報を含む方針・本文・タイトルは同スクリプトへ渡さず、機密を除いた内容だけを整理して、機密原文への出典リンクを付ける。機密を含まない原文は、単発なら `register-ai-prompt.sh`、繰り返し確認後の知識化なら `save-ai-prompt.sh` を利用する。同スクリプトは渡された原文と呼び出し側が選んだ方針を通常領域へ保存し、`register-ai-prompt.sh` は指定された保存先へプロンプト原文を登録する。何を知識として抽出するか、繰り返しの傾向があるか、機密情報に当たるかは呼び出し側が判断する。どちらを使う場合も、スクリプトの引数や保存形式は再定義しない。
8. **確認して報告する**: 保存先、出典、確認日、リンク先、未検証事項を確認する。変更したファイルと残った未確認事項を報告する。

## 出力先

- 機密情報を含まない単発の observation: [04-materials](../../../04-materials/README.md) の配置ルールに従う。
- 繰り返しが確認された knowledge: [02-knowledge](../../../02-knowledge/README.md) の配置ルールと知識メモの雛形に従う。
- rule: 常時守らせたい意図がユーザーから明示された場合に限り、[知識ライフサイクルの判断手順](../knowledge-lifecycle/SKILL.md)に従って適切な保存先を選ぶ。
- 機密情報を含む原文と単発の observation: `01-secret/` の機密情報ルールに従い、`01-secret/prompts/` に保存して通常の領域へ複写しない。

## 確認方法

- 原文と、その出典・確認日を確認できること。確認できないものは未確認と明記すること。
- 1件だけの記録を傾向として扱わず、2件以上でも繰り返しが確認できなければ knowledge に昇格していないこと。
- 頻度だけで rule に昇格しておらず、常時守らせたい意図の明示がある場合はその出典が記録されていること。
- 知識メモの出典リンクから保存済みプロンプトの原文へたどれること。
- 機密情報が通常の知識領域へ転記されておらず、未検証の主張が検証済みとして記録されていないこと。
- 保存スクリプトの機械的な処理と、呼び出し側の内容判断が重複していないこと。
