# 作業手順

AIが参照する作業手順を置く。作業ごとにフォルダを作り、手順を `SKILL.md` にまとめる。
目的、使う場面、入力、手順、出力先、確認方法を記載する。
機械的な処理は[scripts](../../scripts/README.md)に実装し、手順から呼び出し方を案内する。
全体の配置ルールは[00-rules](../../00-rules/workflow.md)に従う。

ここはリポジトリ内の手順置き場。利用するAIツールの自動検出・インストール設定とは別に管理する。

## 個別手順

- [作業に関連するナレッジの絞り込み](filter-related-knowledge/SKILL.md): 02の知識を選び、出典・作業条件・前例を分けて確認し、今回の作業への適用方法を示す。
- [スキル評価](skill-evaluation/SKILL.md): 同じ入力と評価基準でスキル成果をAIが仮採点し、比較条件と結果、ユーザーによる確認を記録する。
- [AIプロンプトの収集と傾向分析](prompt-trend-analysis/SKILL.md): Claude/Codexのセッション収集、04への記録、反復する指摘・判断基準の分析。
- [保存済みプロンプトの知識化](prompt-knowledge/SKILL.md): 04の原文を参照し、反復の根拠と02の既存メモを確認して知識の追加・更新・見送りを判断する。
