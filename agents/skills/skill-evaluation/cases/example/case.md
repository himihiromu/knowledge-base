# ケース: example

- 確認日: 2026-10-01
- 状態: 検証済み。動作確認の記録は[スキル評価の結果](../../../../../03-output/skill-evaluation/README.md)。

評価機構の動作確認用の明示サンプルであり、実在するスキルを参照しない。
対象スキルが空の状態でも、採点→記録→比較の経路を最後まで確認できる。

## 入力

「個人ナレッジベースの運用の要点を、後から見返せるメモ1枚にまとめる」

## 実行方法

- 対象スキルが存在する場合: その SKILL.md の手順に従い、上記の入力を渡して成果を作る。
- 対象スキルが存在しない場合: 次の成果サンプルを評価対象に読み替える。
  - [成果サンプル v1](sample-output-v1.md): 必須記録項目が意図的に欠けた架空の成果
  - [成果サンプル v2](sample-output-v2.md): 必須記録項目が揃った架空の成果

## 評価基準

1. **必須記録項目**: 確認日・状態・出典が書かれている。
2. **出典と推測の区別**: 出典が具体的で、推測を事実として書いていない。
3. **参照リンク**: 参照しているファイルへの相対リンクが張られている。

採点の対象は成果そのもの。成果サンプルを評価するとき、ファイルに付された動作確認用の注記（架空の成果である旨と対応ケースへの案内）は成果に含めず、基準1〜3の根拠に数えない。

## 成果サンプルについて

v1・v2 ともに架空の成果であり、実成果物ではない。評価機構の採点→記録→比較の動作確認専用に作った。
実際の評価では、対象スキルを実行して作った成果を使う。
