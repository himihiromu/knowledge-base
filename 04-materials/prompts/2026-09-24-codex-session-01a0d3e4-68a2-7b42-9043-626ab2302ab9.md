## Example Composition

`video/assets/console/ConsoleAssetSample.tsx`に使用例を実装した。

同一画面に次の2種類を配置する。

- 左側
  - `static` Variant
  - 1倍速
  - 登場・退出なし
  - スクロール補間なし

- 右側
  - `animated` Variant
  - 2倍速
  - 登場・退出あり
  - `ease-in-out-cubic`によるスクロール補間

サンプルデータにはcommand、全出力種別、明示色、長文、複数行、空行、タブ、表示領域を超える出力を含めた。`src/Root.tsx`の`ConsoleAssetSample` Compositionから、登場、退出、スクロール補間を個別に切り替えられる。

## Props Documentation

必須Propsは`events`のみ。

| Props | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `events` | `readonly ConsoleEvent[]` | 必須 | commandとoutputのイベント配列 |
| `prompt` | `string` | `"$"` | commandイベント共通のprompt |
| `playbackRate` | `number` | `1` | 文字、行、command後待機の速度倍率 |
| `framesPerCharacter` | `number` | `2` | command一文字当たりの基準フレーム数 |
| `lineIntervalInFrames` | `number` | `6` | output表示行の追加間隔 |
| `commandToOutputDelayInFrames` | `number` | `8` | command完了からoutput開始までの待機時間 |
| `holdInFrames` | `number` | `45` | 最終表示状態の保持時間 |
| `width` | `number \| \`${number}%\`` | `"80%"` | Console幅 |
| `height` | `number \| \`${number}%\`` | `"62%"` | Console高さ |
| `position` | `ConsolePosition` | `"center"` | 画面内の9方向配置 |
| `offsetX` | `number` | `0` | 配置後の水平移動量 |
| `offsetY` | `number` | `0` | 配置後の垂直移動量 |
| `columns` | `number` | `80` | 決定論的な折り返し文字数 |
| `autoScroll` | `boolean` | `true` | 最新行への自動追従 |
| `scrollAnimation` | `ConsoleScrollAnimation` | 有効、6フレーム、`ease-out-cubic` | スクロール時間とeasing |
| `variant` | `"static" \| "animated"` | `"animated"` | Animationの既定値セット |
| `enter` | `ConsoleAnimation` | 有効、12フレーム | 登場時のopacity、scale、Y移動、easing |
| `exit` | `ConsoleAnimation` | 有効、12フレーム | 退出時のopacity、scale、Y移動、easing |
| `theme` | `ConsoleThemeOverrides` | 既定Theme | 色、フォント、余白、枠、影の部分上書き |

`ConsoleAnimation`は次の任意項目を持つ。

- `enabled`
- `durationInFrames`
- `fromOpacity`
- `toOpacity`
- `fromScale`
- `toScale`
- `fromTranslateY`
- `toTranslateY`
- `easing`

利用可能なeasingは次の4種類。

- `linear`
- `ease-in-cubic`
- `ease-out-cubic`
- `ease-in-out-cubic`

最小使用例:

```tsx
<ConsoleAsset
  events={[
    {id: "command", type: "command", command: "npm test"},
    {
      id: "result",
      type: "output",
      kind: "success",
      text: "All tests passed",
    },
  ]}
/>
```

Animation指定例:

```tsx
<ConsoleAsset
  events={events}
  variant="animated"
  scrollAnimation={{
    enabled: true,
    durationInFrames: 8,
    easing: "ease-in-out-cubic",
  }}
  exit={{
    enabled: true,
    durationInFrames: 18,
    toOpacity: 0,
    toScale: 0.95,
    toTranslateY: -20,
    easing: "ease-in-cubic",
  }}
/>
```

## Known Limitations

- 文字分割は`Array.from()`によるUnicode code point単位であり、結合文字やZWJ emojiのgrapheme clusterを分割する場合がある。
- 色とshadowはCSS文字列として受け取るため、文字列構文の完全な妥当性はTypeScriptでは保証しない。
- 折り返しはDOM計測ではなく`columns`による固定文字数方式である。フォントと幅に応じた調整が必要。
- 実際の色、折り返し、登場・退出、自動スクロールのブラウザ上の視覚確認は未実施。
- 通常データおよび大量行データの実レンダー性能測定は未実施。
- ブラウザ依存の検証はワークフローの完了条件および差し戻し条件から除外されている。
