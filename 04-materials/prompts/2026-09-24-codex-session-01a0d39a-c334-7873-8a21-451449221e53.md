# asset-design.md

## Component Overview

`ConsoleAsset`は、Remotion動画内でコマンド入力とコンソール出力をフレーム同期で順次表示する、OS非依存の再利用可能なAsset Componentである。

現在フレーム、Composition設定、Propsのみから以下を決定する。

- コマンドの表示文字数
- 表示済みの出力行
- 出力種別ごとの色
- 自動スクロール位置
- 登場・退出アニメーション

タイマー、乱数、DOM計測、Reactの逐次的なstate更新、外部API、レンダリング時のファイル読み込みには依存しない。

## Props Interface

```ts
type ConsoleOutputKind =
  | 'default'
  | 'info'
  | 'success'
  | 'warning'
  | 'error';

type ConsolePosition =
  | 'top-left'
  | 'top-center'
  | 'top-right'
  | 'center-left'
  | 'center'
  | 'center-right'
  | 'bottom-left'
  | 'bottom-center'
  | 'bottom-right';

type ConsoleVariant = 'static' | 'animated';

type ConsoleCommandEvent = Readonly<{
  id: string;
  type: 'command';
  prompt?: string;
  command: string;
  startFrame?: number;
}>;

type ConsoleOutputEvent = Readonly<{
  id: string;
  type: 'output';
  text: string;
  kind?: ConsoleOutputKind;
  color?: string;
  startFrame?: number;
}>;

type ConsoleEvent = ConsoleCommandEvent | ConsoleOutputEvent;

type ConsoleAnimation = Readonly<{
  enabled?: boolean;
  durationInFrames?: number;
}>;

type ConsoleScrollAnimation = Readonly<{
  enabled?: boolean;
  durationInFrames?: number;
}>;

type ConsoleTheme = Readonly<{
  backgroundColor: string;
  textColor: string;
  promptColor: string;
  outputColors: Readonly<Record<ConsoleOutputKind, string>>;
  borderColor: string;
  borderWidth: number;
  borderRadius: number;
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  paddingInline: number;
  paddingBlock: number;
  shadow: string;
}>;

type ConsoleThemeOverrides = Readonly<
  Omit<Partial<ConsoleTheme>, 'outputColors'> & {
    outputColors?: Partial<ConsoleTheme['outputColors']>;
  }
>;

type ConsoleAssetProps = Readonly<{
  events: readonly ConsoleEvent[];
  prompt?: string;
  playbackRate?: number;
  framesPerCharacter?: number;
  lineIntervalInFrames?: number;
  commandToOutputDelayInFrames?: number;
  holdInFrames?: number;
  width?: number | `${number}%`;
  height?: number | `${number}%`;
  position?: ConsolePosition;
  offsetX?: number;
  offsetY?: number;
  columns?: number;
  autoScroll?: boolean;
  scrollAnimation?: ConsoleScrollAnimation;
  enter?: ConsoleAnimation;
  exit?: ConsoleAnimation;
  variant?: ConsoleVariant;
  theme?: ConsoleThemeOverrides;
}>;
```

`events`のみ必須とする。

| Props | 説明 | デフォルト値 |
| --- | --- | --- |
| `events` | command/outputイベント配列 | 必須 |
| `prompt` | イベント固有値がない場合のプロンプト | `"$"` |
| `playbackRate` | 内容表示速度の倍率 | `1` |
| `framesPerCharacter` | 1文字当たりの基準フレーム数 | `2` |
| `lineIntervalInFrames` | 出力行の基準追加間隔 | `6` |
| `commandToOutputDelayInFrames` | command完了後の待機時間 | `8` |
| `holdInFrames` | 最終状態の保持時間 | `45` |
| `width` | コンソール幅 | `"80%"` |
| `height` | コンソール高さ | `"62%"` |
| `position` | Composition内の配置 | `"center"` |
| `offsetX` | 水平移動量 | `0` |
| `offsetY` | 垂直移動量 | `0` |
| `columns` | 決定論的な折り返し文字数 | `80` |
| `autoScroll` | 最新行への自動追従 | `true` |
| `scrollAnimation` | スクロール補間設定 | `{enabled: true, durationInFrames: 6}` |
| `enter` | 登場アニメーション | `{enabled: true, durationInFrames: 12}` |
| `exit` | 退出アニメーション | `{enabled: true, durationInFrames: 12}` |
| `variant` | 表示バリエーション | `"animated"` |
| `theme` | Themeの部分上書き | 既定Theme |

commandイベントの`prompt`は共通`prompt`より優先する。outputイベントの`color`は`kind`に対応するTheme色より優先する。Variant既定値の適用後に明示されたアニメーション設定をフィールド単位でマージする。

## Composition

```text
ConsoleAsset
└── AbsoluteFill
    ├── EnterSequence
    │   └── ConsoleViewport
    ├── ContentSequence
    │   └── ConsoleViewport
    │       └── ConsoleContent
    │           ├── CommandLine
    │           └── OutputLine × windowing対象行
    ├── HoldSequence
    │   └── ConsoleViewport
    └── ExitSequence
        └── ConsoleViewport
```

各要素の責務は以下のとおり。

- `ConsoleAsset`: Props、Theme、Variant、Timeline、Layoutの統合
- `ConsoleViewport`: 背景、枠、角丸、影、padding、クリッピング
- `ConsoleContent`: 表示行の配置と`translateY`
- `CommandLine`: プロンプトと入力途中のコマンド表示
- `OutputLine`: 折り返し後の1表示行
- `resolveOutputColor`: 出力色の解決
- `buildTimeline`: イベント開始・終了フレームの計算
- `deriveVisibleConsole`: 現在フレームの表示内容の導出
- `wrapConsoleText`: 改行、空行、タブ、長文の分割
- `calculateScrollOffset`: スクロール目標値の算出
- `resolveScrollAnimation`: 補間済みスクロール位置の算出
- `resolveConsoleAnimation`: 登場・退出の表示値の算出
- `ConsoleAssetSample`: 動作確認用Composition

0より長い区間だけを兄弟`Sequence`として生成する。各区間で同じviewportを重複描画しない。退出無効時は最終表示をComposition終端まで継続する。

## Animation Spec

使用するRemotion APIは以下とする。

- `useCurrentFrame()`
- `useVideoConfig()`
- `Sequence`
- `AbsoluteFill`
- `interpolate()`
- `Easing`

登場は既定12フレームで、`Easing.out(Easing.cubic)`を使用する。継続フレーム数を`d`、Sequenceのローカルフレームを`f`とし、`d >= 2`では入力範囲を`[0, d - 1]`とする。

```ts
opacity = p;
scale = 0.96 + 0.04 * p;
translateY = 16 * (1 - p);
```

退出は既定12フレームで、`Easing.in(Easing.cubic)`を使用する。

```ts
opacity = 1 - q;
scale = 1 - 0.02 * q;
translateY = -12 * q;
```

継続が1フレームの場合は唯一の描画フレームを終端値とする。無効または0フレームの場合は該当するSequenceを生成しない。

スクロールは直前のoffsetから新しい目標offsetまで、既定6フレームで`Easing.out(Easing.cubic)`補間する。補間中に次の行が追加された場合、その境界フレームの補間値を新しい開始値として次の補間を開始する。

`autoScroll=false`ではoffsetを0にする。スクロールアニメーションが無効または0フレームの場合は目標値へ即時移動し、1フレームの場合は境界フレームで目標値へ到達する。

内容表示速度は以下の式で統一する。

```ts
const speedFrames = (baseFrames: number, playbackRate: number): number =>
  baseFrames === 0
    ? 0
    : Math.max(1, Math.round(baseFrames / playbackRate));
```

速度倍率は文字間隔、出力行間隔、command後の待機へ適用する。登場、保持、退出、明示された`startFrame`には適用しない。

## State

`useState`、`useEffect`、タイマーは使用しない。

正規化済みPropsとイベントからTimelineを純粋計算し、絶対フレームから以下を導出する。

- 表示済みイベント
- commandの表示済み文字数
- outputの表示済み行
- スクロール補間の開始値と目標値
- 現在のscroll offset
- 登場・退出アニメーション値

Timeline、折り返し結果、スクロール境界は`useMemo()`で前処理できるが、描画の正しさはmemoizationへ依存させない。同じProps、fps、Composition duration、フレームでは常に同じ結果を返す。

## Theme/Variant

既定Themeは以下とする。

```ts
const defaultConsoleTheme: ConsoleTheme = {
  backgroundColor: '#10141C',
  textColor: '#E6EDF3',
  promptColor: '#7EE787',
  outputColors: {
    default: '#E6EDF3',
    info: '#79C0FF',
    success: '#7EE787',
    warning: '#E3B341',
    error: '#FF7B72',
  },
  borderColor: '#30363D',
  borderWidth: 1,
  borderRadius: 16,
  fontFamily: 'monospace',
  fontSize: 28,
  lineHeight: 42,
  paddingInline: 32,
  paddingBlock: 28,
  shadow: '0 18px 50px rgba(0, 0, 0, 0.35)',
};
```

Themeは既定値へ浅くマージし、`outputColors`のみキー単位でマージする。全子コンポーネントは解決済みThemeを受け取り、子側に色や寸法を固定しない。

Variantは以下の2種類とする。

- `static`: 登場・退出を既定で無効にする。イベントの順次表示は維持する。
- `animated`: 登場・退出を既定で有効にし、それぞれ12フレームとする。

明示された`enter`と`exit`はVariantの既定値より優先する。

## Layout

`AbsoluteFill`を外枠とし、`position`をflexの`alignItems`と`justifyContent`へ変換する。`offsetX`と`offsetY`は配置後のpixel移動として適用する。

幅と高さはpixel値またはCompositionに対する割合を受け付け、既定は80%×62%。割合値は`useVideoConfig()`のComposition寸法からpixelへ解決する。

内容領域高は以下で算出する。

```ts
resolvedHeight - 2 * borderWidth - 2 * paddingBlock
```

表示可能行数は`max(1, floor(contentHeight / lineHeight))`とする。viewportには`box-sizing: border-box`と`overflow: hidden`を適用する。

長文はブラウザの自動折り返しに依存せず、改行で論理行へ分割した後、Unicode code point単位で`columns`文字ごとに分割する。空行は1行として保持し、タブは4個の空白へ正規化する。

スクロール目標値は以下で算出する。

```ts
max(0, visibleVisualLineCount * lineHeight - contentHeight)
```

大量行では表示済み全行をDOM化しない。スクロール補間の開始offsetと目標offsetが必要とする範囲に上下1行をoverscanし、その範囲と交差する行だけを描画する。

## Timeline

累積規則は以下とする。

1. `contentStart = enter.enabled ? enter.durationInFrames : 0`
2. `startFrame`未指定の最初のイベントは`contentStart`から開始
3. command継続時間は`codePointCount(command) * effectiveFramesPerCharacter`
4. command後にoutputが続く場合は`effectiveCommandToOutputDelay`を加算
5. output継続時間は`wrappedLineCount(text) * effectiveLineInterval`
6. 明示`startFrame`はAsset先頭基準の絶対フレームとして自動開始値を置換
7. `contentEnd`は全イベント終了フレームの最大値
8. `holdEnd = contentEnd + holdInFrames`
9. `exitStart = holdEnd`
10. `totalDuration = holdEnd + effectiveExitDuration`

30fps、commandが`npm test`、折り返し後のoutputが3行、既定設定の場合は以下となる。

| フレーム | 状態 |
| ---: | --- |
| 0–11 | 登場。フレーム11でopacity 1、scale 1、Y 0へ到達 |
| 12 | promptとcommand先頭文字を表示 |
| 12–27 | commandを2フレーム/文字で表示 |
| 28–35 | command確定後の待機 |
| 36 | output 1行目を追加 |
| 42 | output 2行目を追加 |
| 48–53 | output 3行目を追加し、必要ならスクロール |
| 54–98 | 最終状態を45フレーム保持 |
| 99–110 | 退出。フレーム110でopacity 0へ到達 |
| 111以降 | 非表示 |

`playbackRate=2`では文字間隔1、行間隔3、command後待機4フレームとなる。登場、保持、退出の継続フレーム数は変化しない。

## Constraints

- `id`は兄弟イベント間で一意とする。
- フレーム値は有限の0以上の整数とする。
- `playbackRate`は有限の正数とする。
- 寸法、列数、Theme数値は有限の正数とし、`borderWidth`のみ0を許可する。
- `lineHeight >= fontSize`を要求する。
- 解決後の内容領域高は正数でなければならない。
- CSS色とshadow文字列の構文は呼び出し側が保証する。
- 既定フォントは外部読込を必要としない`monospace`とする。
- 固有フォントはComposition側で読込完了後に指定する。
- Timeline計算には`ConsoleAsset`直下の絶対フレームを使用する。
- 多数行ではTimelineと折り返しをメモ化し、表示済み末尾を二分探索し、viewport周辺だけをwindowing描画する。
- Unicode文字処理はcode point単位であり、grapheme cluster単位ではない。
- `any`、乱数、副作用、レンダリング時の外部I/Oを使用しない。
- 既存Theme型やComposition登録規則との接続が必要な場合は、公開Propsを維持したadapterを使用する。
