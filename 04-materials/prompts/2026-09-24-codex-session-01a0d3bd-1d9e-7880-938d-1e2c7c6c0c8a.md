# asset-design.md

# Asset Design Report

## Component Overview

`ConsoleAsset`は、Remotion動画内でコマンド入力と出力行をフレーム同期で表示する、OS非依存の再利用可能なコンソールAssetである。

現在フレーム、Composition設定、Propsのみから表示文字、表示行、スクロール位置、登場・退出状態を決定する。タイマー、乱数、DOM計測、外部I/Oには依存しない。

## Props Interface

必須Props:

- `events: readonly ConsoleEvent[]`
  - コマンドと出力イベントの配列。
  - `ConsoleCommandEvent`
    - `id: string`
    - `type: 'command'`
    - `command: string`
    - `prompt?: string`
    - `startFrame?: number`
  - `ConsoleOutputEvent`
    - `id: string`
    - `type: 'output'`
    - `text: string`
    - `kind?: 'default' | 'info' | 'success' | 'warning' | 'error'`
    - `color?: string`
    - `startFrame?: number`

任意Propsとデフォルト値:

- `prompt?: string`: `'$'`
- `playbackRate?: number`: `1`
- `framesPerCharacter?: number`: `2`
- `lineIntervalInFrames?: number`: `6`
- `commandToOutputDelayInFrames?: number`: `8`
- `holdInFrames?: number`: `45`
- `width?: number | \`${number}%\``: `'80%'`
- `height?: number | \`${number}%\``: `'62%'`
- `position?: ConsolePosition`: `'center'`
- `offsetX?: number`: `0`
- `offsetY?: number`: `0`
- `columns?: number`: `80`
- `autoScroll?: boolean`: `true`
- `scrollAnimation?: ConsoleScrollAnimation`: `{enabled: true, durationInFrames: 6}`
- `enter?: ConsoleAnimation`: `{enabled: true, durationInFrames: 12}`
- `exit?: ConsoleAnimation`: `{enabled: true, durationInFrames: 12}`
- `variant?: 'static' | 'animated'`: `'animated'`
- `theme?: ConsoleThemeOverrides`: 既定Themeをフィールド単位で上書きする。

`ConsolePosition`は上下左右と中央を組み合わせた9位置を受け付ける。イベント固有の`prompt`はトップレベル値より優先し、出力の`color`は`kind`に対応するTheme色より優先する。

フレーム値は有限の0以上の整数、`playbackRate`は有限の正数として検証する。

## Composition

レンダリング構成:

```text
ConsoleAsset
└── AbsoluteFill
    └── Sequence
        └── ConsoleViewport
            └── ConsoleContent
                ├── CommandLine
                └── OutputLine[]
```

責務:

- `ConsoleAsset`: Props、Theme、Variant、Timeline、Layout、アニメーションの統合。
- `ConsoleViewport`: 背景、枠線、角丸、影、padding、クリッピング。
- `ConsoleContent`: 表示行の整列とスクロール変換。
- `CommandLine`: promptと入力途中を含むcommandの表示。
- `OutputLine`: 折り返し後の個々の出力行の表示。
- `buildTimeline`: イベント開始・終了フレームの純粋計算。
- `deriveVisibleConsole`: 現在フレームにおける表示内容の導出。
- `wrapConsoleText`: 改行、空行、タブ、折り返しの正規化。
- `calculateScrollOffset`: スクロール目標値の算出。
- `resolveScrollAnimation`: スクロール補間。
- `resolveConsoleAnimation`: 登場・退出の表示値算出。
- `ConsoleAssetSample`: 動作確認用Composition。

## Animation Spec

使用するRemotion API:

- `useCurrentFrame()`
- `useVideoConfig()`
- `Sequence`
- `AbsoluteFill`
- `interpolate()`
- `Easing`

登場アニメーションは既定12フレームで、`Easing.out(Easing.cubic)`を使用する。

- opacity: `0 → 1`
- scale: `0.96 → 1`
- translateY: `16 → 0`

退出アニメーションは既定12フレームで、`Easing.in(Easing.cubic)`を使用する。

- opacity: `1 → 0`
- scale: `1 → 0.98`
- translateY: `0 → -12`

補間値は左右ともclampする。継続時間が1フレームの場合は、そのフレームで終端値を適用する。無効時または0フレーム時は登場を即時完了し、退出は生成しない。

内容の実効フレーム数は次の規則で算出する。

```ts
baseFrames === 0
  ? 0
  : Math.max(1, Math.round(baseFrames / playbackRate));
```

この速度変換は文字間隔、行間隔、コマンド後待機に適用し、登場、保持、退出には適用しない。

スクロールは既定6フレーム、`Easing.out(Easing.cubic)`で直前offsetから新しい目標offsetへ補間する。

## State

`useState`、`useEffect`、タイマーは使用しない。

正規化済みPropsとイベント配列からTimelineを`useMemo`で算出し、表示済みイベント、コマンド文字数、表示行、スクロール位置を絶対フレームから純粋に導出する。

`useMemo`は性能最適化に限定し、描画結果の正しさには影響させない。同じProps、fps、Composition duration、frameに対して常に同じ描画結果を返す。

## Theme/Variant

Themeで以下を設定する。

- 背景色
- 本文色
- prompt色
- 5種類の出力色
- 枠線色、枠線幅
- 角丸
- フォント
- 文字サイズ
- 行高
- 水平・垂直padding
- 影

既定Themeは暗色背景、明色本文、generic familyの`monospace`を使用する。`outputColors`は種別単位、その他はフィールド単位で上書きできる。

Variant:

- `static`
  - 登場・退出を既定で無効化する。
  - イベントの順次表示は維持する。
- `animated`
  - 登場・退出を各12フレームで有効化する。

明示された`enter`と`exit`はVariantの既定値より優先する。

## Layout

`AbsoluteFill`内で、`position`をflexの配置へ変換する。配置後に`offsetX`、`offsetY`をpixel単位で適用する。

幅と高さはpixel値またはCompositionに対する割合を受け付ける。既定値は幅80%、高さ62%。

内容領域高は次の式で算出する。

```text
resolvedHeight - 2 × borderWidth - 2 × paddingBlock
```

長文はブラウザの自動折り返しに依存せず、`columns`ごとにUnicode code point単位で分割する。改行と空行を保持し、タブは4個の空白へ正規化する。

大量行ではviewport周辺と上下1行のoverscanだけを描画し、全行のDOM生成を避ける。

## Timeline

既定の累積規則:

1. 登場が有効ならフレーム0から12フレーム登場する。
2. 内容開始は登場完了フレーム。登場無効時はフレーム0。
3. commandは`framesPerCharacter`ごとに1文字表示する。
4. command完了後、`commandToOutputDelayInFrames`だけ待機する。
5. outputは折り返し後の行を`lineIntervalInFrames`ごとに追加する。
6. 最終行後、`holdInFrames`だけ最終状態を保持する。
7. 退出が有効なら保持完了後に退出する。
8. 退出無効時はComposition終端まで最終状態を表示する。

`startFrame`指定時はAsset先頭からの絶対フレームとして、自動算出したイベント開始位置を置換する。前のイベントより早い値も許可し、イベントを同時表示できる。

30fps、`npm test`、3出力行の既定例:

- 0–11: 登場
- 12–27: 2フレームごとのコマンド入力
- 28–35: コマンド後待機
- 36: 1行目追加
- 42: 2行目追加
- 48: 3行目追加
- 48–53: 必要な場合のスクロール補間
- 54–98: 最終状態保持
- 99–110: 退出
- 111以降: 非表示

## Constraints

- `any`は使用しない。
- レンダリング中にAPI呼び出しやファイル読み込みを行わない。
- `Math.random()`や副作用を使用しない。
- DOM計測へ依存しない。
- 既定フォントは外部読込不要の`monospace`とする。
- `columns`は実際のフォントと幅に合わせてComposition側で調整する。
- 既存Theme型、Asset配置規則、Composition登録規則、利用可能な等幅フォントは提供入力では未確認。
- `id`は兄弟イベント間で一意とする。
- `lineHeight >= fontSize`を必須とする。
- 同じ開始フレームのイベントは配列順で表示する。
