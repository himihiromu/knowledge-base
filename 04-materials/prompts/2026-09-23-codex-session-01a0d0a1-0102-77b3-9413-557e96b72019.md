# asset-design.md

## Component Overview

`ConsoleAsset`は、Remotion動画内でコマンド入力とコンソール出力をフレーム同期で順次表示する、OS非依存の再利用可能なAsset Componentである。

現在フレーム、Composition設定、Propsだけから次を決定する。

- コマンドの表示文字数
- 表示済みの出力行
- 出力種別ごとの色
- 自動スクロール位置
- 登場・退出アニメーションの進捗

タイマー、乱数、DOM計測、外部API、レンダリング時のファイル読み込みには依存しない。同一のProps、Composition設定、フレームから常に同一の描画結果を生成する。

## Props Interface

```ts
type ConsoleOutputKind =
  | 'default'
  | 'info'
  | 'success'
  | 'warning'
  | 'error';

type ConsolePosition =
  | 'top-left'
  | 'top-center'
  | 'top-right'
  | 'center-left'
  | 'center'
  | 'center-right'
  | 'bottom-left'
  | 'bottom-center'
  | 'bottom-right';

type ConsoleVariant = 'static' | 'animated';

type ConsoleCommandEvent = Readonly<{
  id: string;
  type: 'command';
  prompt?: string;
  command: string;
  startFrame?: number;
}>;

type ConsoleOutputEvent = Readonly<{
  id: string;
  type: 'output';
  text: string;
  kind?: ConsoleOutputKind;
  color?: string;
  startFrame?: number;
}>;

type ConsoleEvent = ConsoleCommandEvent | ConsoleOutputEvent;

type ConsoleAnimation = Readonly<{
  enabled?: boolean;
  durationInFrames?: number;
}>;

type ConsoleTheme = Readonly<{
  backgroundColor: string;
  textColor: string;
  promptColor: string;
  outputColors: Readonly<Record<ConsoleOutputKind, string>>;
  borderColor: string;
  borderWidth: number;
  borderRadius: number;
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  paddingInline: number;
  paddingBlock: number;
  shadow: string;
}>;

type ConsoleAssetProps = Readonly<{
  events: readonly ConsoleEvent[];
  prompt?: string;
  playbackRate?: number;
  framesPerCharacter?: number;
  lineIntervalInFrames?: number;
  commandToOutputDelayInFrames?: number;
  holdInFrames?: number;
  width?: number | `${number}%`;
  height?: number | `${number}%`;
  position?: ConsolePosition;
  offsetX?: number;
  offsetY?: number;
  columns?: number;
  autoScroll?: boolean;
  enter?: ConsoleAnimation;
  exit?: ConsoleAnimation;
  variant?: ConsoleVariant;
  theme?: Partial<ConsoleTheme> & Readonly<{
    outputColors?: Partial<ConsoleTheme['outputColors']>;
  }>;
}>;
```

`events`だけを必須とする。各Propsの役割とデフォルト値は次のとおり。

| Props | 説明 | デフォルト |
| --- | --- | --- |
| `events` | コマンドと出力のイベント配列 | 必須 |
| `prompt` | commandイベントに個別指定がない場合のプロンプト | `"$"` |
| `playbackRate` | 内容表示速度の倍率 | `1` |
| `framesPerCharacter` | コマンド1文字当たりの基準フレーム数 | `2` |
| `lineIntervalInFrames` | 出力表示行の基準追加間隔 | `6` |
| `commandToOutputDelayInFrames` | コマンド完了から出力開始までの基準待機時間 | `8` |
| `holdInFrames` | 最終表示状態の保持時間 | `45` |
| `width` | コンソール幅 | `"80%"` |
| `height` | コンソール高さ | `"62%"` |
| `position` | Composition内の配置 | `"center"` |
| `offsetX` | 配置後の水平移動量 | `0` |
| `offsetY` | 配置後の垂直移動量 | `0` |
| `columns` | 1表示行の最大文字数 | `80` |
| `autoScroll` | 最新行が見える位置への自動スクロール | `true` |
| `variant` | 表示バリエーション | `"animated"` |
| `enter` | 登場の有効状態と継続時間 | `{enabled: true, durationInFrames: 12}` |
| `exit` | 退出の有効状態と継続時間 | `{enabled: true, durationInFrames: 12}` |
| `theme` | Themeの部分上書き | 既定Theme |

commandイベントの`prompt`はトップレベルの`prompt`より優先する。outputイベントの`color`は`kind`に対応するTheme色より優先する。

フレーム値は0以上の有限整数、`playbackRate`は正の有限数とする。`id`は兄弟イベント間で一意とする。`any`は使用しない。

## Composition

レンダリングツリーは次の構成とする。

```text
ConsoleAsset
└── AbsoluteFill
    └── ConsoleViewport
        └── ConsoleContent
            ├── CommandLine
            │   ├── Prompt
            │   └── CommandText
            └── OutputLine × 表示済み表示行数
```

各構成要素の責務は次のとおり。

- `ConsoleAsset`
  - 公開コンポーネント
  - Props、Theme、Variant、Timelineの解決
  - `useCurrentFrame()`と`useVideoConfig()`による描画状態の導出
- `ConsoleViewport`
  - 背景、枠、角丸、影、padding、クリッピング
- `ConsoleContent`
  - 表示行の縦配置とスクロール用`translateY`
- `CommandLine`
  - プロンプトと入力途中を含むコマンド文字列の表示
- `OutputLine`
  - 折り返し処理後の1表示行の描画
- `resolveOutputColor`
  - 明示色または出力種別に対応するTheme色の解決
- `buildTimeline`
  - 各イベントの実効開始・終了フレームの計算
- `deriveVisibleConsole`
  - 現在フレームにおける表示文字と表示行の導出
- `wrapConsoleText`
  - 改行、空行、タブ、長文の決定論的な表示行分割
- `calculateScrollOffset`
  - 表示行数と内容領域高からスクロール量を算出
- `resolveConsoleAnimation`
  - opacity、scale、translateYの算出
- `ConsoleAssetSample`
  - 複数種別、長文、自動スクロール、速度変更、アニメーション切替の確認用Composition

`Sequence`を登場、各イベント、保持、退出の時間区間の明示に使用する。表示済み行は個別Sequenceの状態ではなく、Asset先頭からの絶対フレームで一括導出する。

## Animation Spec

使用するRemotion APIは次のとおり。

- `useCurrentFrame()`
- `useVideoConfig()`
- `Sequence`
- `AbsoluteFill`
- `interpolate()`
- `Easing`

登場アニメーションは12フレームを既定とする。進捗`p`を次の補間で求める。

```ts
interpolate(frame, [0, enterDuration], [0, 1], {
  extrapolateLeft: 'clamp',
  extrapolateRight: 'clamp',
  easing: Easing.out(Easing.cubic),
});
```

表示値は次のとおり。

- `opacity = p`
- `scale = 0.96 + 0.04 * p`
- `translateY = 16 * (1 - p)`

退出アニメーションは12フレームを既定とする。退出開始以降の進捗`q`を次の補間で求める。

```ts
interpolate(frame, [exitStart, exitStart + exitDuration], [0, 1], {
  extrapolateLeft: 'clamp',
  extrapolateRight: 'clamp',
  easing: Easing.in(Easing.cubic),
});
```

表示値は次のとおり。

- `opacity = 1 - q`
- `scale = 1 - 0.02 * q`
- `translateY = -12 * q`

無効なアニメーションは実効継続時間を0フレームとし、0フレームの`Sequence`は生成しない。

内容表示速度は次の式で統一する。

```ts
const speedFrames = (
  baseFrames: number,
  playbackRate: number,
): number =>
  baseFrames === 0
    ? 0
    : Math.max(1, Math.round(baseFrames / playbackRate));
```

速度倍率は文字間隔、出力行間隔、コマンド後の待機時間へ適用する。登場、最終状態保持、退出の継続時間には適用しない。

## State

Reactの`useState`、`useEffect`、タイマーによる逐次更新は使用しない。

正規化されたPropsとイベント配列からTimelineを純粋計算し、現在フレームから以下を導出する。

- 表示済みイベント
- commandの表示済み文字数
- outputの表示済み行数
- 最新行を表示するスクロール量
- 登場・退出アニメーション値

Timeline計算には性能最適化として`useMemo`を使用できるが、計算結果の正しさはmemoizationに依存させない。イベント追加順やスクロール位置を可変stateとして保持しないため、任意フレームの直接レンダリングでも同じ結果になる。

## Theme/Variant

既定Themeは次のとおり。

```ts
const defaultConsoleTheme: ConsoleTheme = {
  backgroundColor: '#10141C',
  textColor: '#E6EDF3',
  promptColor: '#7EE787',
  outputColors: {
    default: '#E6EDF3',
    info: '#79C0FF',
    success: '#7EE787',
    warning: '#E3B341',
    error: '#FF7B72',
  },
  borderColor: '#30363D',
  borderWidth: 1,
  borderRadius: 16,
  fontFamily: 'monospace',
  fontSize: 28,
  lineHeight: 42,
  paddingInline: 32,
  paddingBlock: 28,
  shadow: '0 18px 50px rgba(0, 0, 0, 0.35)',
};
```

Themeは既定Themeへ部分マージする。`outputColors`はオブジェクト全体を置換せず、出力種別ごとにマージする。

Variantは次の2種類とする。

- `static`
  - 登場・退出を既定で無効化
  - フレーム0から不透明、等倍で表示
  - commandとoutputの順次表示は維持
- `animated`
  - 登場・退出を既定で有効化
  - 各アニメーションは12フレーム

明示された`enter`と`exit`はVariantの既定設定より優先する。これにより登場だけ、退出だけ、両方、どちらもなしの4構成を表現できる。

## Layout

`AbsoluteFill`内で`position`をflexの`alignItems`と`justifyContent`へ変換する。位置決定後に`offsetX`と`offsetY`をpixel単位で適用する。

幅と高さはpixelまたはCompositionに対する割合で指定できる。割合指定は`useVideoConfig()`から取得したCompositionの幅と高さを使ってpixelへ解決する。

viewportは次の条件を持つ。

- `box-sizing: border-box`
- `overflow: hidden`
- Theme由来の枠線、角丸、padding、影
- OS固有のタイトルバーや操作ボタンを持たない

内容領域高は次の式で求める。

```text
contentHeight =
  resolvedHeight
  - 2 × borderWidth
  - 2 × paddingBlock
```

表示可能行数は次の式で求める。

```text
max(1, floor(contentHeight / lineHeight))
```

長文はブラウザの自動折り返しに依存させない。`wrapConsoleText`で改行を保持し、各論理行を`columns`文字ごとに分割する。

- 空行は高さを持つ1行として保持
- タブは4個の空白へ正規化
- 文字列は`Array.from()`でUnicode code point単位に分割
- 各表示行は`white-space: pre`と固定行高で描画

自動スクロール量は次の式で求める。

```text
max(
  0,
  visibleVisualLineCount × lineHeight - contentHeight
)
```

`autoScroll=false`の場合は0とする。スクロールは`ConsoleContent`の`translateY(-offsetPx)`で適用し、最新行の下端を内容領域の下端へ合わせる。

## Timeline

Timelineの累積規則は次のとおり。

1. 登場が有効なら、内容開始は登場継続時間後とする。
2. 最初のイベントは、明示`startFrame`がなければ内容開始フレームから開始する。
3. commandの継続時間は文字数×実効文字間隔とする。
4. command後に実効待機時間を追加してoutputを開始する。
5. outputは折り返し後の表示行ごとに実効行間隔で追加する。
6. `startFrame`が指定されたイベントは、その絶対フレームを自動計算値より優先する。
7. 最後のイベント終了後に`holdInFrames`だけ最終状態を保持する。
8. 保持終了後に退出を開始する。
9. 退出無効時はComposition終端まで表示を続ける。

既定値、30 fps、`playbackRate=1`、commandが`npm test`、outputが折り返し後3行の場合は次のTimelineになる。

| フレーム | 状態 |
| ---: | --- |
| 0–11 | 12フレームで登場 |
| 12 | promptとcommand先頭文字を表示 |
| 12–27 | commandを2フレームごとに順次表示 |
| 28–35 | command確定後の待機 |
| 36 | output 1行目を追加 |
| 42 | output 2行目を追加 |
| 48 | output 3行目を追加し、必要ならスクロール |
| 54–98 | 最終状態を45フレーム保持 |
| 99–110 | 12フレームで退出 |
| 111以降 | 非表示 |

`playbackRate=2`では文字間隔1、行間隔3、command後待機4フレームとなる。登場12、保持45、退出12フレームは変更しない。明示された`startFrame`にも速度倍率は適用しない。

## Constraints

- TypeScriptでは判別可能Unionとreadonly型を使用し、`any`を使用しない。
- 同一フレームの描画結果を決定論的にする。
- レンダリング中に外部API、ファイル、フォント取得を行わない。
- DOM計測には依存しない。
- 既定フォントはCSS generic familyの`monospace`とする。
- 特定フォントを使う場合はComposition側で事前に読み込み、Theme経由で指定する。
- `columns`は実際の幅とフォントに合わせてComposition側で調整する。
- `lineHeight`は`fontSize`以上でなければならない。
- イベントIDは一意でなければならない。
- `startFrame`などのフレーム値は0以上の整数に限定する。
- 既存Theme型、Asset配置規則、Composition登録規則、利用可能な等幅フォント、既存Assetの有無は、提供された入力では未確認。
- 実装時にはAsset用READMEと確認用Compositionを作成し、Catalogを更新する必要がある。
