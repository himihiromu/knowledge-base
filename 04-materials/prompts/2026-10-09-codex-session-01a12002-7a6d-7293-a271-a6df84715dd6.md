# coder-scope.md

# 変更スコープ宣言

## タスク

mise から任意の作業ディレクトリでローカル Nix 設定を操作できるようにし、bash に指定された略語と検索キー操作を実装する。

## 変更予定

| 種別 | ファイル |
|------|---------|
| 作成 | `dot_config/mise/config.toml` |
| 変更 | `dot_bashrc` |
| 変更 | `.chezmoiignore` |
| 変更 | `.tests/bash_shell_test.sh` |

## 推定規模

Medium

## 影響範囲

- mise の Nix タスク
- bash の略語、zoxide 初期化、Ctrl+R・Ctrl+U の検索操作
- chezmoi による mise 設定の管理対象判定
- bash 設定のテスト coverage

# coder-decisions.md

# 決定ログ

## 1. mise タスクで対象リポジトリと操作を明示

- **背景**: 任意のカレントディレクトリから、ローカルの Nix 設定を使って操作する必要がありました。
- **検討した選択肢**: 各タスクに対象パスとコマンドを直接指定する／共通 wrapper を追加する。
- **理由**: 計画に従い、追加の wrapper を導入せず、各タスクから `$HOME/ghq/github.com/himihiromu/my-nix-package-control` を参照する形にしました。引数不足や未知のサブコマンドでは操作を起動しないようにしています。

## 2. bash の検索キー用 widget を関数として定義

- **背景**: Ctrl+R の履歴検索と Ctrl+U の ghq リポジトリ検索で、選択結果をそれぞれ入力行と作業ディレクトリへ反映する必要がありました。
- **検討した選択肢**: キー割当へ処理を直接書く／widget 関数を定義して割り当てる。
- **理由**: 関数で処理を定義し、Readline に割り当てました。隔離スタブを使うテストで、zoxide 初期化、履歴の選択結果、リポジトリへの移動を確認できる形にしています。
