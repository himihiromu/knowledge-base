# asset-design.md

## Component Overview

`ConsoleAsset`は、Remotion動画内でコマンド入力とコンソール出力をフレーム同期で順次表示する、OS非依存の再利用可能なAsset Componentである。

現在フレーム、Composition設定、Propsのみから以下を決定する。

- コマンドの表示文字数
- 表示済みの出力行
- 出力種別ごとの色
- 補間された自動スクロール位置
- 登場・退出アニメーション

タイマー、乱数、DOM計測、Reactの逐次的なstate更新、外部API、レンダリング時のファイル読み込みには依存しない。

## Props Interface

```ts
type ConsoleOutputKind =
  | 'default'
  | 'info'
  | 'success'
  | 'warning'
  | 'error';

type ConsolePosition =
  | 'top-left'
  | 'top-center'
  | 'top-right'
  | 'center-left'
  | 'center'
  | 'center-right'
  | 'bottom-left'
  | 'bottom-center'
  | 'bottom-right';

type ConsoleVariant = 'static' | 'animated';

type ConsoleCommandEvent = Readonly<{
  id: string;
  type: 'command';
  prompt?: string;
  command: string;
  startFrame?: number;
}>;

type ConsoleOutputEvent = Readonly<{
  id: string;
  type: 'output';
  text: string;
  kind?: ConsoleOutputKind;
  color?: string;
  startFrame?: number;
}>;

type ConsoleEvent = ConsoleCommandEvent | ConsoleOutputEvent;

type ConsoleAnimation = Readonly<{
  enabled?: boolean;
  durationInFrames?: number;
}>;

type ConsoleScrollAnimation = Readonly<{
  enabled?: boolean;
  durationInFrames?: number;
}>;

type ConsoleTheme = Readonly<{
  backgroundColor: string;
  textColor: string;
  promptColor: string;
  outputColors: Readonly<Record<ConsoleOutputKind, string>>;
  borderColor: string;
  borderWidth: number;
  borderRadius: number;
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  paddingInline: number;
  paddingBlock: number;
  shadow: string;
}>;

type ConsoleThemeOverrides = Readonly<
  Omit<Partial<ConsoleTheme>, 'outputColors'> & {
    outputColors?: Partial<ConsoleTheme['outputColors']>;
  }
>;

type ConsoleAssetProps = Readonly<{
  events: readonly ConsoleEvent[];
  prompt?: string;
  playbackRate?: number;
  framesPerCharacter?: number;
  lineIntervalInFrames?: number;
  commandToOutputDelayInFrames?: number;
  holdInFrames?: number;
  width?: number | `${number}%`;
  height?: number | `${number}%`;
  position?: ConsolePosition;
  offsetX?: number;
  offsetY?: number;
  columns?: number;
  autoScroll?: boolean;
  scrollAnimation?: ConsoleScrollAnimation;
  enter?: ConsoleAnimation;
  exit?: ConsoleAnimation;
  variant?: ConsoleVariant;
  theme?: ConsoleThemeOverrides;
}>;
```

`events`のみ必須とする。

| Props | 説明 | デフォルト |
| --- | --- | --- |
| `events` | command/outputイベント配列 | 必須 |
| `prompt` | command固有値がない場合のプロンプト | `"$"` |
| `playbackRate` | 内容表示速度の倍率 | `1` |
| `framesPerCharacter` | 1文字当たりの基準フレーム数 | `2` |
| `lineIntervalInFrames` | 出力行の基準追加間隔 | `6` |
| `commandToOutputDelayInFrames` | command完了後の待機時間 | `8` |
| `holdInFrames` | 最終表示状態の保持時間 | `45` |
| `width` | コンソール幅 | `"80%"` |
| `height` | コンソール高さ | `"62%"` |
| `position` | Composition内の配置 | `"center"` |
| `offsetX` | 配置後の水平移動量 | `0` |
| `offsetY` | 配置後の垂直移動量 | `0` |
| `columns` | 決定論的な折り返し文字数 | `80` |
| `autoScroll` | 最新行への自動追従 | `true` |
| `scrollAnimation` | スクロール補間の設定 | `{enabled: true, durationInFrames: 6}` |
| `variant` | 表示バリエーション | `"animated"` |
| `enter` | 登場アニメーション設定 | `{enabled: true, durationInFrames: 12}` |
| `exit` | 退出アニメーション設定 | `{enabled: true, durationInFrames: 12}` |
| `theme` | Themeの部分上書き | 既定Theme |

commandイベントの`prompt`は共通`prompt`より優先する。outputイベントの`color`は`kind`に対応するTheme色より優先する。

## Composition

```text
ConsoleAsset
└── AbsoluteFill
    ├── EnterSequence
    │   └── ConsoleViewport
    ├── ContentSequence
    │   └── ConsoleViewport
    │       └── ConsoleContent
    │           ├── CommandLine
    │           └── OutputLine × windowing対象行
    ├── HoldSequence
    │   └── ConsoleViewport
    └── ExitSequence
        └── ConsoleViewport
```

各区間では同じviewportを重複描画しない。

- `ConsoleAsset`: Props、Theme、Timeline、Layoutの統合
- `ConsoleViewport`: 背景、枠、角丸、影、padding、クリッピング
- `ConsoleContent`: 表示行の配置と`translateY`
- `CommandLine`: プロンプトと入力途中のコマンド表示
- `OutputLine`: 折り返し後の1表示行
- `buildTimeline`: イベント開始・終了フレームの計算
- `deriveVisibleConsole`: 現在フレームの表示内容を導出
- `wrapConsoleText`: 改行、空行、タブ、長文の分割
- `calculateScrollOffset`: スクロール目標値の算出
- `resolveScrollAnimation`: 補間済みスクロール位置の算出
- `resolveConsoleAnimation`: 登場・退出の表示値を算出
- `ConsoleAssetSample`: 動作確認用Composition

## Animation Spec

使用するRemotion APIは以下とする。

- `useCurrentFrame()`
- `useVideoConfig()`
- `Sequence`
- `AbsoluteFill`
- `interpolate()`
- `Easing`

登場は既定12フレームで、`Easing.out(Easing.cubic)`を使用する。

```ts
const p = interpolate(frame, [0, enterDuration], [0, 1], {
  extrapolateLeft: 'clamp',
  extrapolateRight: 'clamp',
  easing: Easing.out(Easing.cubic),
});
```

- `opacity = p`
- `scale = 0.96 + 0.04 * p`
- `translateY = 16 * (1 - p)`

退出は既定12フレームで、`Easing.in(Easing.cubic)`を使用する。

```ts
const q = interpolate(
  frame,
  [exitStart, exitStart + exitDuration],
  [0, 1],
  {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.in(Easing.cubic),
  },
);
```

- `opacity = 1 - q`
- `scale = 1 - 0.02 * q`
- `translateY = -12 * q`

スクロールは直前のoffsetから新しい目標offsetまで、既定6フレームで`Easing.out(Easing.cubic)`補間する。補間中に次の行が追加された場合、その境界フレームの補間値を新しい開始値として次の補間を開始する。

`autoScroll=false`ではoffsetを0にする。スクロールアニメーションが無効または0フレームの場合は目標値へ即時移動する。

内容表示速度は次の式で統一する。

```ts
const speedFrames = (baseFrames: number, playbackRate: number): number =>
  baseFrames === 0
    ? 0
    : Math.max(1, Math.round(baseFrames / playbackRate));
```

速度倍率は文字間隔、出力行間隔、command後の待機へ適用し、登場、保持、退出には適用しない。

## State

`useState`、`useEffect`、タイマーは使用しない。

正規化済みPropsとイベントからTimelineを純粋計算し、絶対フレームから以下を導出する。

- 表示済みイベント
- commandの表示済み文字数
- outputの表示済み行
- スクロール補間の開始値と目標値
- 現在のscroll offset
- 登場・退出アニメーション値

Timeline前処理には`useMemo()`を利用できるが、描画の正しさはmemoizationへ依存させない。同じProps、Composition設定、フレームでは常に同じ結果を返す。

## Theme/Variant

既定Themeは次のとおり。

```ts
const defaultConsoleTheme: ConsoleTheme = {
  backgroundColor: '#10141C',
  textColor: '#E6EDF3',
  promptColor: '#7EE787',
  outputColors: {
    default: '#E6EDF3',
    info: '#79C0FF',
    success: '#7EE787',
    warning: '#E3B341',
    error: '#FF7B72',
  },
  borderColor: '#30363D',
  borderWidth: 1,
  borderRadius: 16,
  fontFamily: 'monospace',
  fontSize: 28,
  lineHeight: 42,
  paddingInline: 32,
  paddingBlock: 28,
  shadow: '0 18px 50px rgba(0, 0, 0, 0.35)',
};
```

Themeは既定値へ部分マージする。`outputColors`は出力種別ごとに部分上書きする。

Variantは以下の2種類とする。

- `static`: 登場・退出を既定で無効化し、内容の順次表示は維持する
- `animated`: 登場・退出を既定で有効化し、それぞれ12フレームとする

明示された`enter`と`exit`はVariant既定値より優先する。

## Layout

`AbsoluteFill`内で`position`をflex配置へ変換し、`offsetX`と`offsetY`をpixel単位で適用する。

幅と高さはpixelまたはCompositionに対する割合で指定する。割合値は`useVideoConfig()`の解像度を使ってpixelへ解決する。

```text
contentHeight =
  resolvedHeight
  - 2 × borderWidth
  - 2 × paddingBlock
```

表示可能行数は次で求める。

```text
max(1, floor(contentHeight / lineHeight))
```

長文はブラウザの自動折り返しへ依存せず、`columns`単位で分割する。

- 改行を保持
- 空行を高さのある1行として保持
- タブを4個の空白へ変換
- Unicode code point単位で分割
- 固定行高と`white-space: pre`で描画

自動スクロールの目標値は次のとおり。

```text
max(
  0,
  visibleVisualLineCount × lineHeight - contentHeight
)
```

多数行ではviewport周辺だけをwindowingして描画する。

## Timeline

累積規則は以下とする。

1. `contentStart`は有効な登場アニメーションの終了フレーム。
2. 最初のイベントは、明示値がなければ`contentStart`から開始する。
3. commandの継続時間は文字数×実効文字間隔。
4. command後に実効待機時間を追加する。
5. outputは折り返し後の行ごとに実効行間隔で追加する。
6. `startFrame`はAsset先頭基準の絶対フレームとして自動値より優先する。
7. `contentEnd`は全イベントの終了フレームの最大値。
8. `holdEnd = contentEnd + holdInFrames`。
9. `exitStart = holdEnd`。
10. スクロール目標値が増える行追加フレームをスクロール境界とする。

既定値、30fps、`npm test`、output 3行の場合は以下となる。

| フレーム | 状態 |
| ---: | --- |
| 0–11 | 登場アニメーション |
| 12 | promptとcommand先頭文字を表示 |
| 12–27 | commandを2フレームごとに表示 |
| 28–35 | command後の待機 |
| 36 | output 1行目 |
| 42 | output 2行目 |
| 48 | output 3行目。必要なら6フレームのスクロール補間開始 |
| 54–98 | 最終状態を保持 |
| 99–110 | 退出アニメーション |
| 111以降 | 非表示 |

`Sequence`は登場、内容、保持、退出を実際の時間区間として分割する。継続時間が0のSequenceは生成しない。退出無効時は最終状態を親Compositionの終端まで表示する。

## Constraints

- TypeScriptの判別可能Unionとreadonly型を使用し、`any`を使用しない。
- フレーム値は0以上の有限整数とする。
- `playbackRate`は正の有限数とする。
- イベントIDは配列内で一意とする。
- `lineHeight`は`fontSize`以上とする。
- 内容領域高は正数でなければならない。
- レンダリング中の外部API、ファイル、フォント取得を禁止する。
- DOM計測、乱数、副作用を使用しない。
- 既定フォントはCSS generic familyの`monospace`とする。
- `Sequence`内のローカルフレームを絶対Timeline計算へ使用しない。
- 0フレームのSequenceを生成しない。
- `columns`は使用するフォントと表示幅に合わせて呼び出し側で調整する。
- 実装時にAsset README、サンプルComposition、Asset Catalogを用意する。
