## Props Documentation

### `ComparisonAssetProps`

| Prop | 型 | 説明 | デフォルト |
| --- | --- | --- | --- |
| `title` | `string` | 画面全体のタイトル。空白のみは不可 | 必須 |
| `items` | `ComparisonItems` | 2〜4件の比較項目tuple | 必須 |
| `variant` | `"auto" \| "two" \| "three" \| "four"` | レイアウト指定。明示指定時は件数との一致が必要 | `"auto"` |
| `durationInFrames` | `number` | Asset全体の継続フレーム数 | `180` |
| `animation` | `ComparisonAnimation` | 登場タイミングと動き | 開始15、間隔12、時間18、移動比率0.04、開始scale 0.96 |
| `theme` | `ComparisonTheme` | 配色、枠線、余白、文字、画像サイズの部分上書き | プロジェクトTheme対応値 |
| `labels` | `ComparisonLabels` | メリット、デメリット、省略表示の文言 | `Pros`、`Cons`、`…` |
| `contentLimits` | `ComparisonContentLimits` | タイトル、説明、リストの表示上限 | 2行、3行、2行、3項目 |

### `ComparisonItem`

```ts
type ComparisonItem = {
  id: string;
  title: string;
  description?: string;
  image?: {
    src: string;
    alt: string;
    fit?: "contain" | "cover";
    position?: string;
  };
  rating?: {
    value: number;
    max: number;
    label?: string;
  };
  pros?: readonly string[];
  cons?: readonly string[];
  badge?: string;
};
```

- `id`: 配列内で一意な非空文字列。
- `title`: 必須のカードタイトル。
- `description`: 任意の説明文。
- `image`: Remotionが表示可能な解決済みURLと代替テキスト。
- `rating`: `max > 0`かつ`0 <= value <= max`の評価値。
- `pros`: メリット一覧。
- `cons`: デメリット一覧。
- `badge`: カード上部の補足表示。

空の任意文字列と空配列は表示領域を生成しない。装飾画像のため、画像の`alt`には空文字を指定できる。

### `ComparisonAnimation`

```ts
type ComparisonAnimation = {
  startFrame?: number;
  cardStaggerFrames?: number;
  cardDurationFrames?: number;
  enterOffsetRatio?: number;
  enterScale?: number;
};
```

最後のカードが`durationInFrames`内に登場を完了できない設定は、実行時検証で拒否する。

### `ComparisonTheme`

以下をカテゴリ単位・キー単位で部分上書きできる。

- `colors`: 背景、タイトル、カード、補助文字、枠線、バッジ、評価、メリット、デメリット。
- `border`: 幅と`solid`、`dashed`、`double`のスタイル。
- `radius`: カード、バッジ、画像の角丸。
- `spacing`: 画面余白、タイトル間隔、グリッド間隔、カード余白、セクション間隔。
- `typography`: フォント、文字サイズ比率、ウェイト、行高。
- `image`: アスペクト比と最大高比率。

不正な型、負の値、範囲外の比率、無効な枠線スタイルは実行時検証で拒否する。

### `ComparisonContentLimits`

```ts
type ComparisonContentLimits = {
  titleLines?: number;
  descriptionLines?: number;
  listItemLines?: number;
  listItems?: number;
};
```

各値は1以上の整数として検証する。テキストはCSS line-clampで省略し、リストが上限を超えた場合は最後の表示項目へ`overflowIndicator`を付加する。

### 使用例

```tsx
import {staticFile} from "remotion";
import {
  ComparisonAsset,
  type ComparisonItems,
} from "./video/assets";

const items = [
  {
    id: "alpha",
    title: "Alpha",
    image: {
      src: staticFile("products/alpha.png"),
      alt: "Alpha product",
    },
    rating: {value: 4.5, max: 5, label: "Score"},
    pros: ["Fast", "Simple"],
    badge: "Recommended",
  },
  {
    id: "beta",
    title: "Beta",
    description: "More control for advanced workflows.",
    cons: ["Longer setup"],
  },
] satisfies ComparisonItems;

export const Scene = () => (
  <ComparisonAsset
    title="Alpha vs Beta"
    items={items}
    durationInFrames={180}
    animation={{
      startFrame: 15,
      cardStaggerFrames: 12,
      cardDurationFrames: 18,
    }}
    labels={{pros: "Benefits", cons: "Trade-offs"}}
    theme={{colors: {badgeBackground: "#2563eb"}}}
  />
);
```

## Known Limitations

- 比較項目数は2〜4件に限定される。
- 3件表示は縦長Compositionでも横3列を維持するため、文章量を表示上限内に抑える必要がある。
- `object-position`文字列の完全なCSS構文検証は行わない。
- AssetとCompositionで同じ`durationInFrames`を指定する必要がある。
- Remotion 4.0.484の型制約により、`Sequence`の`layout="none"`と`premountFor`を併用していない。代わりにSequenceを早期開始し、論理開始フレームまではopacity 0を維持する。
- 実ブラウザでのフレームレンダー、Studioでの目視確認、目標解像度での性能測定は未実施。
- 既存のメイン`src/Root.tsx`にはExample Compositionを登録せず、専用の`ComparisonAsset.root.tsx`を使用する。
