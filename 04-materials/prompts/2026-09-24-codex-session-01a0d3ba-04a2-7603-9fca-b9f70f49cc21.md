## Example Composition

`ConsoleAssetSample`を1920×1080、30fps、240フレームのCompositionとして`src/Root.tsx`へ登録した。

サンプルは同じイベントデータを左右に表示する。

- 左側: `static` Variant、1倍速、登場・退出なし、スクロール補間なし
- 右側: `animated` Variant、2倍速、登場・退出あり、6フレームのスクロール補間
- `default`、`info`、`success`、`warning`、`error`の全出力種別
- イベント固有色
- 改行、空行、タブ、長文の折り返し
- Viewportを超える行数と自動スクロール
- スクロール補間中に次の行が追加されるタイミング

Compositionの`defaultProps`から右側の登場、退出、スクロール補間を個別に切り替えられる。

コード参照:

- `video/assets/console/ConsoleAssetSample.tsx`
- `src/Root.tsx`

## Props Documentation

`ConsoleAssetProps`は`events`のみ必須で、その他にはデフォルト値を定義した。

| Props | 型 | デフォルト値 | 説明 |
| --- | --- | --- | --- |
| `events` | `readonly ConsoleEvent[]` | 必須 | command/outputイベント配列 |
| `prompt` | `string` | `"$"` | commandイベント固有値がない場合のプロンプト |
| `playbackRate` | `number` | `1` | 文字、出力行、command後待機の速度倍率 |
| `framesPerCharacter` | `number` | `2` | command 1文字当たりの基準フレーム数 |
| `lineIntervalInFrames` | `number` | `6` | output表示行の基準追加間隔 |
| `commandToOutputDelayInFrames` | `number` | `8` | command完了からoutput開始までの基準待機時間 |
| `holdInFrames` | `number` | `45` | 最終表示状態から退出までの保持時間 |
| `width` | `number \| \`${number}%\`` | `"80%"` | コンソール幅 |
| `height` | `number \| \`${number}%\`` | `"62%"` | コンソール高さ |
| `position` | `ConsolePosition` | `"center"` | 9方向の配置 |
| `offsetX` | `number` | `0` | 配置後の水平pixel移動 |
| `offsetY` | `number` | `0` | 配置後の垂直pixel移動 |
| `columns` | `number` | `80` | 決定論的な折り返し文字数 |
| `autoScroll` | `boolean` | `true` | 最新行への自動追従 |
| `scrollAnimation` | `ConsoleScrollAnimation` | `{enabled: true, durationInFrames: 6}` | スクロール補間設定 |
| `variant` | `"static" \| "animated"` | `"animated"` | アニメーションの既定動作 |
| `enter` | `ConsoleAnimation` | Variant依存、12フレーム | 登場アニメーション設定 |
| `exit` | `ConsoleAnimation` | Variant依存、12フレーム | 退出アニメーション設定 |
| `theme` | `ConsoleThemeOverrides` | 既定Theme | 色、フォント、行高、余白、枠線、角丸、影の部分上書き |

イベント型:

- command: `id`、`type: "command"`、`command`、任意の`prompt`と`startFrame`
- output: `id`、`type: "output"`、`text`、任意の`kind`、`color`、`startFrame`
- output種別: `default`、`info`、`success`、`warning`、`error`
- イベント固有の`prompt`は共通`prompt`より優先
- output固有の`color`はThemeの種別色より優先
- `startFrame`はAsset先頭からの絶対フレーム

最小使用例:

```tsx
import {ConsoleAsset} from "./video/assets/console";

export const Demo = () => (
  <ConsoleAsset
    events={[
      {id: "command", type: "command", command: "npm test"},
      {
        id: "result",
        type: "output",
        kind: "success",
        text: "All tests passed",
      },
    ]}
  />
);
```

ThemeとAnimationの使用例:

```tsx
<ConsoleAsset
  events={events}
  variant="animated"
  scrollAnimation={{enabled: true, durationInFrames: 8}}
  enter={{enabled: false}}
  exit={{enabled: true, durationInFrames: 18}}
  theme={{
    backgroundColor: "#020617",
    outputColors: {warning: "#facc15"},
    fontFamily: "monospace",
  }}
/>
```

## Known Limitations

- 文字分割は`Array.from()`によるUnicode code point単位であり、結合文字やZWJ emojiのgrapheme clusterを途中で分割する場合がある。
- 色とshadowはCSS文字列として受け取るため、TypeScriptだけではCSS構文の妥当性を保証しない。
- 折り返しはDOM計測を使わず`columns`で決定するため、利用フォントやViewport幅に応じた調整が必要。
- 外部フォントはAsset内で読み込まない。Composition側で読み込みを完了してから`theme.fontFamily`へ指定する必要がある。
- Chrome Headless Shellを取得できない環境だったため、実フレームレンダーと1920×1080での性能ベンチマークは未実施。
