# Asset Implementation Report

## Implemented Files

- `video/assets/ComparisonAsset.tsx`
  - 2〜4件の比較項目を表示する再利用可能なReact/Remotionコンポーネント。
  - 2件は2列、3件は3列、4件は2×2グリッドで表示。
  - `Sequence`、`useCurrentFrame()`、`useVideoConfig()`、`interpolate()`、`Easing`、`Img`を使用。
  - カードを配列順に段階表示。
  - Theme、Variant、アニメーション、表示文字数制限に対応。
  - tuple unionと実行時検証を併用。
  - 既存プロジェクトThemeの背景、surface、文字色、枠線、フォントをデフォルトThemeへ対応付け。
  - 任意項目は要素ごと条件描画し、未指定領域を残さない。
  - 静的表示コンポーネントへ`React.memo()`を適用。

- `video/assets/ComparisonAsset.examples.tsx`
  - 2件、3件、4件のExample Composition用コンポーネント。
  - 画像、評価、メリット、デメリット、バッジ、任意項目省略を網羅。
  - 外部通信を必要としないdata URL画像を使用。
  - Composition設定を`comparisonExampleCompositions`として公開。

- `video/assets/ComparisonAsset.root.tsx`
  - Example CompositionをRemotion Studioで直接開くためのエントリポイント。
  - `ComparisonAsset-Two`、`ComparisonAsset-Three`、`ComparisonAsset-Four`を登録。

- `video/assets/index.ts`
  - コンポーネント、公開型、検証関数、Example Compositionのbarrel export。

- `video/assets/README.md`
  - 導入方法、Composition登録例、Props、画像URL契約、レイアウト、文字省略規則、Theme互換性、Studio起動方法を記載。

## Props Documentation

### `ComparisonAssetProps`

| Prop | 型 | 説明 | デフォルト |
| --- | --- | --- | --- |
| `title` | `string` | 画面全体のタイトル。空白文字のみは不可 | 必須 |
| `items` | `ComparisonItems` | 2〜4件の比較項目tuple | 必須 |
| `variant` | `'auto' \| 'two' \| 'three' \| 'four'` | レイアウト指定。明示指定時は件数との一致が必要 | `'auto'` |
| `durationInFrames` | `number` | Asset全体の継続フレーム数 | `180` |
| `animation` | `ComparisonAnimation` | 登場タイミングと動きの設定 | 下記参照 |
| `theme` | `ComparisonTheme` | 配色、枠線、余白、文字、画像サイズの部分上書き | 既存Theme対応値 |
| `labels` | `ComparisonLabels` | メリット、デメリット、省略表示の文言 | `Pros`、`Cons`、`…` |
| `contentLimits` | `ComparisonContentLimits` | タイトル、説明、リストの表示上限 | 下記参照 |

### `ComparisonItem`

```ts
type ComparisonItem = {
  id: string;
  title: string;
  description?: string;
  image?: ComparisonImage;
  rating?: ComparisonRating;
  pros?: readonly string[];
  cons?: readonly string[];
  badge?: string;
};
```

- `id`: React keyおよび項目識別子。同一配列内で一意かつ空白以外。
- `title`: カードタイトル。
- `description`: 任意の説明文。
- `image`: `src`、`alt`、任意の`fit`と`position`。
- `rating`: `value`、`max`、任意の`label`。`max > 0`かつ`0 <= value <= max`。
- `pros`: メリット一覧。
- `cons`: デメリット一覧。
- `badge`: カード上部の補足バッジ。

空の任意文字列と空配列は対応領域を描画しない。装飾画像のため、画像の`alt`は空文字も許可する。

### `ComparisonAnimation`

```ts
type ComparisonAnimation = {
  startFrame?: number;
  cardStaggerFrames?: number;
  cardDurationFrames?: number;
  enterOffsetRatio?: number;
  enterScale?: number;
};
```

デフォルト値:

- `startFrame`: `15`
- `cardStaggerFrames`: `12`
- `cardDurationFrames`: `18`
- `enterOffsetRatio`: `0.04`
- `enterScale`: `0.96`

フレーム値は有限整数として検証する。最後のカードの登場完了フレームより短い`durationInFrames`はエラーになる。

### `ComparisonTheme`

次のカテゴリを末端キー単位で部分上書きできる。

- `colors`: 背景、タイトル、カード、補助文字、枠線、バッジ、評価、メリット、デメリットの色。
- `border`: 枠線幅と`solid`、`dashed`、`double`のスタイル。
- `radius`: カード、バッジ、画像の角丸。
- `spacing`: 画面余白、タイトル間隔、グリッド間隔、カード余白、セクション間隔。
- `typography`: フォント、各文字サイズ比率、太さ、行高。
- `image`: アスペクト比とカード高に対する最大高。

負の枠線、余白、角丸、文字サイズ、不正な比率、CSS範囲外のウェイトなどは実行時検証で拒否する。

### `ComparisonContentLimits`

デフォルト値:

- `titleLines`: `2`
- `descriptionLines`: `3`
- `listItemLines`: `2`
- `listItems`: `3`

テキストはCSS line-clampで省略する。リストが`listItems`を超える場合、最後の表示項目へ`overflowIndicator`を付加する。

### 使用例

```tsx
import {staticFile} from "remotion";
import {
  ComparisonAsset,
  type ComparisonItems,
} from "./video/assets";

const items = [
  {
    id: "alpha",
    title: "Alpha",
    image: {
      src: staticFile("products/alpha.png"),
      alt: "Alpha product",
    },
    rating: {value: 4.5, max: 5, label: "Score"},
    pros: ["Fast", "Simple"],
    badge: "Recommended",
  },
  {
    id: "beta",
    title: "Beta",
    description: "More control for advanced workflows.",
    cons: ["Longer setup"],
  },
] satisfies ComparisonItems;

export const Scene = () => (
  <ComparisonAsset
    title="Alpha vs Beta"
    items={items}
    durationInFrames={180}
    animation={{
      startFrame: 15,
      cardStaggerFrames: 12,
      cardDurationFrames: 18,
    }}
    labels={{pros: "Benefits", cons: "Trade-offs"}}
    theme={{colors: {badgeBackground: "#2563eb"}}}
  />
);
```

ローカル画像は呼び出し側で`staticFile()`によりURL化する。data URLも使用可能。リモートURLはレンダー環境のネットワーク可用性に依存する。

## Known Limitations

- 比較項目数は2〜4件に限定される。
- 3件表示は縦長Compositionでも横3列を維持するため、文章量を表示上限内に抑える必要がある。
- `object-position`文字列はブラウザのCSS解釈に委ねており、完全な構文検証は行わない。
- `durationInFrames`はComposition側とAsset側で同じ値を指定する必要がある。
- Remotion 4.0.484の型では`Sequence`の`layout="none"`と`premountFor`を同時指定できない。このため、Sequenceを登場時刻より最大1アニメーション期間早く開始し、登場開始まではopacity 0を維持する方式で事前マウントを実現した。
- 実行環境のsocket制限によりChromiumが起動できず、実ブラウザでのComposition列挙、フレームレンダー、性能計測は未完了。
- 既存のメイン`src/Root.tsx`にはExample Compositionを登録していない。専用の`ComparisonAsset.root.tsx`から確認する構成としている。
