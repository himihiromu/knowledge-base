# AI会話の原文アーカイブ

Claude Code / Codexとのセッションに含まれるユーザーとアシスタントの可視テキストを、1セッション1ファイルで原文のまま保存する。収集範囲を日付で指定しても、選択されたセッションは会話全体を保存する。

各ファイルの本文は発言者ラベル・時刻・会話本文のみ。要約、傾向、分析、メモはここへ記載しない。分析成果物は03、検証済みの再利用知識は02に置く。

収集・登録手順は[スクリプトの記録](../../scripts/README.md)、分析手順は[分析スキル](../../agents/skills/prompt-trend-analysis/SKILL.md)を参照する。
