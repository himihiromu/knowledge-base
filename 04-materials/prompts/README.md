# AIとのプロンプト記録

AI作業中の指摘の原文と、Claude/Codexから取得したセッション単位のユーザー入力を置く場所。
セッション記録は `register-ai-prompt-session.mjs` が `YYYY-MM-DD-取得元-session-ID-タイトル.md` の形式で作る。機密情報や公開可否が不明な個人情報を含むセッションは01へ保存する。
収集・登録・傾向分析の流れは[スクリプトの記録](../../scripts/README.md)と[分析スキル](../../agents/skills/prompt-trend-analysis/SKILL.md)を参照する。
今回の分析結果は[2026-10-10の傾向分析](../prompt-trend-analysis-2026-10-10.md)、その根拠抜粋は[傾向分析用プロンプト原文](2026-10-10-prompt-trend-observations.md)に記録。
ここから抜き出した方針は、02-knowledgeの `ai-work-preferences.md` へ出典リンク付きで集約される（初回の保存時に生成される）。
