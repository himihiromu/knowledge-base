# asset-plan.md

## Overview

Remotion動画向けに、コマンドプロンプト、コマンド、実行結果を順次表示するOS非依存の再利用可能なConsole Assetを計画した。入力イベント、Theme、表示速度、レイアウトを差し替えて複数動画で利用する。

## Purpose

コマンド実行やログ出力を視認性高く説明できるようにする。現在フレームとPropsだけから表示状態を導出し、同一フレームで常に同一結果となる決定的な描画を実現する。

## Target Videos

- コマンド実行手順を説明する動画
- ビルド、テスト、デプロイのログを解説する動画
- CLIツールや開発ワークフローを紹介する動画
- コンソール出力を扱う複数のRemotion作品

## Scenes

1. コンソールウィンドウの登場
2. プロンプトとコマンドの順次表示
3. コマンド出力の行単位での追加
4. 情報、成功、警告、エラーなどの種別別色分け
5. 表示領域超過時の自動スクロール
6. 最終出力の保持と任意の退出アニメーション

長文、複数行、折り返し、空行も同じイベントモデルで扱う。OS固有のタイトルバーや操作ボタンには依存しない。

## Timing

30 fps基準の初期計画値は以下のとおり。

- Asset表示開始: フレーム0
- 登場アニメーション: 12フレーム
- プロンプト表示: フレーム12
- コマンド入力開始: フレーム18
- コマンド表示速度: 2フレーム/文字
- コマンド確定後の待機: 8フレーム
- 出力追加間隔: 6フレーム/行
- 最終状態の保持: 45フレーム
- 退出アニメーション: 12フレーム

各イベントは`startFrame`で個別指定可能とする。表示速度は`playbackRate`に集約し、実効時間を`max(1, round(基準フレーム数 / playbackRate))`で算出する。登場・退出時間は内容の表示速度から独立させる。

Sequenceは、登場、コマンド表示、出力追加、最終状態保持、退出の順で構成する。アニメーション無効時は登場を即時表示とし、退出せずComposition終端まで表示する。

## Features

- 型安全なコマンド・出力イベント配列
- プロンプト、コマンド、出力内容の差し替え
- コマンドの文字単位表示
- 出力の行単位表示
- 出力種別または明示色による色分け
- 長文の折り返し、改行、空行への対応
- 最新行を表示する自動スクロール
- 登場・退出アニメーションの個別有効化
- 通常表示とアニメーション付き表示のVariant
- 背景、文字、プロンプト、出力種別、枠線を変更できるTheme
- 幅、高さ、配置を変更できるレスポンシブなLayout Props
- 現在フレームとPropsから表示状態を導出する決定的レンダリング
- レンダリング時のAPI呼び出しやファイル読み込みを行わない構造
- 動作確認用サンプルComposition
- Asset用README

## Reusability Assessment

再利用可能性は高い。表示内容をイベント配列、外観をTheme、時間をフレーム設定と速度倍率、寸法と位置をLayout Propsとして分離するため、コマンド解説、ビルドログ、テスト結果、デプロイ状況などへ転用できる。

既存Theme型、Asset配置規則、Composition登録規則、利用可能な等幅フォント、既存Assetの有無は提供された入力では未確認である。後続の設計・実装工程で確認し、既存規約や既存Assetが存在する場合はそれらを優先する。
