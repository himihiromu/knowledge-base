# coder-decisions.md

# 決定ログ

## 1. Nix flake のテスト実行を7つの suite に分け、失敗後も続行する
- **背景**: C2 は全 suite の実行と、失敗を非ゼロ終了コードへ反映することを求めている。
- **検討した選択肢**: 7つのテストファイルを個別に起動する／複数のテストをまとめて起動する
- **理由**: 個別起動なら各 suite の実行結果を記録でき、途中の失敗後も残りを実行して最終終了コードへ反映できる。実装結果では、この方式で7 suite の成功と失敗注入後の非ゼロ終了を確認した。

## 2. Nix app と development shell で同じテスト実行定義を使う
- **背景**: 計画はテスト実行を flake の check と development shell からも利用することを求めている。
- **検討した選択肢**: 各出力に個別の実行定義を置く／共通の runner を使う
- **理由**: 共通 runner を使い、`nix run`、`nix flake check`、`nix develop -c run-all-tests` で同じテスト群を実行できる。実装結果では各経路の成功を確認した。
