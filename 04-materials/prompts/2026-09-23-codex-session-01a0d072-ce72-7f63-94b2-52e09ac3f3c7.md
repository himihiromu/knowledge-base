# asset-design.md

## Component Overview

`ComparisonAsset` は、2〜4件の商品、サービス、方式、選択肢を1画面で比較表示する再利用可能なRemotionコンポーネントである。

比較件数に応じて2列、3列、2×2グリッドへ切り替え、配列順にカードを段階表示する。各カードはタイトルを必須とし、説明、画像、評価値、メリット、デメリット、バッジを任意表示する。未指定の情報領域は描画せず、空白を予約しない。

## Props Interface

```ts
export type ComparisonVariant = 'auto' | 'two' | 'three' | 'four';

export type ComparisonImage = {
  src: string;
  alt: string;
  fit?: 'contain' | 'cover';
  position?: string;
};

export type ComparisonRating = {
  value: number;
  max: number;
  label?: string;
};

export type ComparisonItem = {
  id: string;
  title: string;
  description?: string;
  image?: ComparisonImage;
  rating?: ComparisonRating;
  pros?: readonly string[];
  cons?: readonly string[];
  badge?: string;
};

export type ComparisonItems =
  | readonly [ComparisonItem, ComparisonItem]
  | readonly [ComparisonItem, ComparisonItem, ComparisonItem]
  | readonly [
      ComparisonItem,
      ComparisonItem,
      ComparisonItem,
      ComparisonItem,
    ];

export type ComparisonAnimation = {
  startFrame?: number;
  cardStaggerFrames?: number;
  cardDurationFrames?: number;
  enterOffsetRatio?: number;
  enterScale?: number;
};

export type ComparisonTheme = {
  colors?: Partial<{
    background: string;
    title: string;
    cardBackground: string;
    cardText: string;
    mutedText: string;

  border?: Partial<{
    width: number;
    style: 'solid' | 'dashed' | 'double';
  }>;
  radius?: Partial<{
    card: number;
    badge: number;
    image: number;
  }>;
  spacing?: Partial<{
    screenXRatio: number;
    screenYRatio: number;
    titleGapRatio: number;
    gridGapRatio: number;
    cardPaddingRatio: number;
    sectionGapRatio: number;
  }>;
  typography?: Partial<{
    fontFamily: string;
    titleSizeRatio: number;
    cardTitleSizeRatio: number;
    bodySizeRatio: number;
    metaSizeRatio: number;
    titleWeight: number;
    cardTitleWeight: number;
    lineHeight: number;
  }>;
  image?: Partial<{
    aspectRatio: number;
    maxHeightRatio: number;
  }>;
};

export type ComparisonAssetProps = {
  title: string;
  items: ComparisonItems;
  variant?: ComparisonVariant;
  durationInFrames?: number;
  animation?: ComparisonAnimation;
  theme?: ComparisonTheme;
};
```

`title` と `items` は必須であり、デフォルト値を持たない。

デフォルト値は次のとおり。

```ts
const defaultProps = {
  variant: 'auto',
  durationInFrames: 180,
  animation: {
    startFrame: 15,
    cardStaggerFrames: 12,
    cardDurationFrames: 18,
    enterOffsetRatio: 0.04,
    enterScale: 0.96,
  },
} as const;
```

項目内の任意プロパティは未指定をデフォルトとする。`pros` と `cons` は空配列相当として扱う。画像の `fit` は `cover`、`position` は `50% 50%`、評価の `label` は未指定とする。

`id` はReact keyおよび項目識別に使用し、配列内で一意でなければならない。画像の `src` はRemotionで表示可能な解決済みURL文字列とする。

## Composition

レンダリングツリーは次の構成とする。

```text
ComparisonAsset
├── ComparisonHeader
└── ComparisonGrid
    ├── AnimatedComparisonCard
    │   └── ComparisonCard
    │       ├── ComparisonCardHeader
    │       ├── ComparisonImageBlock（任意）
    │       ├── Description（任意）
    │       ├── ComparisonRatingBlock（任意）
    │       ├── ComparisonList: pros（任意）
    │       └── ComparisonList: cons（任意）
    └── ...2〜4件
```

各コンポーネントの責務は次のとおり。

- `ComparisonAsset`: デフォルト値、Theme、Variantの解決、入力検証、動画情報取得、全体配置。
- `ComparisonHeader`: 画面タイトルの表示と折り返し。
- `ComparisonGrid`: 件数別グリッドとカード順序。
- `AnimatedComparisonCard`: `Sequence` とフレーム値による登場状態の算出。
- `ComparisonCard`: 枠、背景、カード内の縦方向レイアウト。
- `ComparisonCardHeader`: 比較対象タイトルと任意バッジ。
- `ComparisonImageBlock`: `Img` による画像表示。
- `ComparisonRatingBlock`: 評価値と評価バー。
- `ComparisonList`: メリットまたはデメリットの一覧。

## Animation Spec

使用するRemotion APIは次のとおり。

- `AbsoluteFill`: 全画面ルート
- `Sequence`: カードごとの表示開始制御
- `useCurrentFrame()`: カードのローカルフレーム取得
- `useVideoConfig()`: 解像度とfpsの取得
- `interpolate()`: 不透明度、移動量、拡大率の算出
- `Easing.out(Easing.cubic)`: 登場終端の減速
- `Img`: Remotion互換の画像表示

カード `i` の開始フレームは次の式で決定する。

```ts
const start = startFrame + i * cardStaggerFrames;
```

`Sequence` は各カードについて次の範囲を持つ。

```ts
from={start}
durationInFrames={durationInFrames - start}
```

登場進捗はカードのローカルフレームから算出する。

```ts
const progress = interpolate(
  frame,
  [0, cardDurationFrames],
  [0, 1],
  {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
    easing: Easing.out(Easing.cubic),
  },
);
```

進捗に応じて次の値を補間する。

- `opacity`: 0から1
- `translateY`: `enterOffsetRatio * availableGridHeight` から0
- `scale`: `enterScale` から1

指定フレーム数で確実に完了させるため、物理的な余韻を持つ `spring()` ではなく `interpolate()` を使用する。

## State

`useState`、Context、イベント状態などの内部可変状態は持たない。

描画結果は次の入力のみから決定する。

- Props
- 解決済みTheme
- `useCurrentFrame()` の現在フレーム
- `useVideoConfig()` の幅、高さ、fps

Themeのマージ、Variant選択、レイアウト値、アニメーション進捗は純粋関数で算出する。同一入力と同一フレームから常に同一結果を生成する。

状態遷移はカードごとに「未表示」「登場中」「表示完了」の3段階であり、フレーム値から直接導出する。

## Theme/Variant

Themeは末端キー単位で部分上書き可能とし、指定されていない値にはデフォルトThemeを使用する。

デフォルトThemeは次の内容を持つ。

- 背景、タイトル、カード、補助文字、枠線、バッジ、評価、メリット、デメリットの色
- 枠線幅2、スタイル `solid`
- カード角丸18、バッジ角丸999、画像角丸12
- 画面余白、グリッド間隔、カード余白、セクション間隔の相対値
- フォント、タイトル・本文・補助文字の相対サイズ
- 画像比率16:9、最大高比率0.24

Variantは次のとおり。

| Variant | 件数 | 配置 |
| --- | ---: | --- |
| `auto` | 2〜4 | 件数から自動決定 |
| `two` | 2 | 1行2列 |
| `three` | 3 | 1行3列 |
| `four` | 4 | 2行2列 |

`auto` 以外のVariantと項目数が一致しない場合は実行時エラーとする。

## Layout

ルートは `AbsoluteFill` でComposition全体を占有する。内部はタイトル行と比較グリッド行から構成する。

```text
grid-template-rows: auto minmax(0, 1fr)
```

件数別グリッドは次のとおり。

| 件数 | columns | rows | 表示順 |
| ---: | --- | --- | --- |
| 2 | `repeat(2, minmax(0, 1fr))` | 1行 | 左、右 |
| 3 | `repeat(3, minmax(0, 1fr))` | 1行 | 左、中央、右 |
| 4 | `repeat(2, minmax(0, 1fr))` | 2行 | 左上、右上、左下、右下 |

画面余白、間隔、カード余白、文字サイズは `min(width, height)` を基準とした相対値で算出する。画像最大高は利用可能なグリッド高を基準とする。

カードには `min-width: 0` と `min-height: 0` を設定する。カード内部は通常の縦方向フローとし、存在するセクションのみ生成する。任意項目がない場合はwrapper、gap、予約高を生成しない。

文字は幅に応じて折り返し、カード本体は `overflow: hidden` とする。暗黙のスクロールは使用しない。

## Timeline

デフォルトは30fps基準、全180フレームである。

| 対象 | 2件 | 3件 | 4件 |
| --- | --- | --- | --- |
| タイトル | 0〜179 | 0〜179 | 0〜179 |
| カード1登場 | 15〜32 | 15〜32 | 15〜32 |
| カード2登場 | 27〜44 | 27〜44 | 27〜44 |
| カード3登場 | — | 39〜56 | 39〜56 |
| カード4登場 | — | — | 51〜68 |
| 全カード完成状態 | 45〜179 | 57〜179 | 69〜179 |

フレーム区間は開始を含み終了を含まない。一般式は次のとおり。

- タイトル表示: `[0, durationInFrames)`
- カード `i` 登場開始: `startFrame + i * cardStaggerFrames`
- カード登場区間: `[開始, 開始 + cardDurationFrames)`
- 全カード完成開始: `startFrame + (items.length - 1) * cardStaggerFrames + cardDurationFrames`

デフォルト30fpsでは、先頭カードは0.5秒後に開始し、カード間隔は0.4秒、登場時間は0.6秒、全体は6秒となる。

## Constraints

- 比較項目数は2〜4件に限定する。
- TypeScriptではtuple unionで件数を制約し、実行時にも件数を検証する。
- Variantと件数の不一致を許容しない。
- `id` は空文字および重複を禁止する。
- 画面タイトルと各カードタイトルは空文字を禁止する。
- `rating.max` は0より大きく、`value` は0以上かつ `max` 以下とする。
- フレーム値は有限整数とし、開始・間隔は0以上、アニメーション時間は1以上とする。
- `enterScale` は0より大きく1以下、`enterOffsetRatio` は0以上とする。
- `durationInFrames` は最後のカードの登場完了フレーム以上とする。
- 空の任意文字列および空配列は非表示として扱う。
- 画像は解決済みURLを受け取り、Asset内でファイル読み込みを行わない。
- レンダリング中にAPI呼び出し、乱数、副作用を使用しない。
- 既存Theme型、Asset export規約、画像URL生成規約との互換性は、提供資料に含まれていないため未確認である。
