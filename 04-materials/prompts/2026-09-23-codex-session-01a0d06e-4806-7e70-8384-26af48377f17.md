# asset-plan.md

## Overview

2〜4件の商品、サービス、方式、選択肢を1画面で比較する、再利用可能なRemotion Asset Componentの計画を作成した。比較件数に応じて2列、3列、2×2グリッドへ切り替え、比較カードを所定の順番で段階表示する。

## Purpose

比較対象の情報を統一されたカード形式で提示し、視聴者が違いや長所・短所を把握しやすくする。任意項目、Theme、Variant、アニメーション設定をProps化し、異なる動画でも共通利用できる構成を目指す。

## Target Videos

- 商品の購入比較動画
- サービスや料金プランの比較動画
- 方式、手法、技術の比較解説動画
- 候補や選択肢を評価するランキング・レビュー動画

特定の動画名およびComposition IDは指定されていない。

## Scenes

1. 画面全体のタイトルを表示して比較テーマを提示する。
2. 2〜4件の比較カードを指定順に登場させる。
3. 各カード上部に比較対象のタイトルを表示する。
4. 指定されたカードに説明文と画像を表示する。
5. 評価値、メリット、デメリット、バッジを必要に応じて表示する。
6. 全カードが揃った状態を保持し、内容を比較する時間を設ける。

レイアウトと表示順は以下とする。

- 2件: 左右2列。左、右の順。
- 3件: 横3列。左、中央、右の順。
- 4件: 2×2グリッド。左上、右上、左下、右下の順。

## Timing

30fps基準のデフォルト構成は以下とする。

- Asset開始: 0フレーム
- タイトル表示: 0フレームから終了まで
- 先頭カード開始: 15フレーム
- カード間隔: 12フレーム
- 各カードの登場アニメーション: 18フレーム
- 全体継続時間: 180フレーム
- カード `i` の開始フレーム: `15 + i × 12`
- 最後のカードのアニメーション完了: 2件は45、3件は57、4件は69フレーム
- 全カード登場後: 180フレーム目まで最終状態を保持

これらのタイミングはPropsで変更可能とし、現在フレームから決定的に表示状態を算出する。

## Features

- 画面全体のタイトル指定
- 2〜4件に制限された比較項目
- 各項目の必須タイトル
- 任意の説明文、画像、評価値、メリット、デメリット、バッジ
- 任意項目がない場合の領域非表示と余白調整
- 件数に応じたレイアウトの自動切り替え
- フェードと移動またはスケールによる順次登場
- 表示開始、カード間隔、アニメーション時間のProps指定
- Theme Propsによる配色、枠線、角丸、余白、文字サイズの指定
- `two`、`three`、`four` Variantと項目数による自動選択
- 相対サイズを用いた解像度・縦横比への対応
- 全カード登場後の静止状態保持
- レンダリング時の外部API呼び出しやファイル読み込みを行わない
- 動画用Assetのためクリック操作などのインタラクションは対象外
- 不正な項目数に対する型安全性と実行時検証

既存Theme型、Asset export規約、画像指定方式は提供資料に含まれず、互換性は未確認であるため、後続の設計・検証工程で確認する。

## Reusability Assessment

再利用可能性は高い。表示内容をProps、外観をTheme、件数別表現をVariant、タイミングをアニメーション設定として分離するため、商品比較以外にもサービス、技術方式、料金プラン、候補評価へ転用できる。

制約は比較対象が2〜4件であることと、1画面で読める情報量に収めることである。5件以上または詳細情報が多い場合は、ページ分割または別Assetを使用する。
