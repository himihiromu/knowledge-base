# Claude/Codexへの指摘・好みの傾向（初回観察）

- 確認日: 2026-10-10
- 対象期間: 2026-08-03〜2026-10-10
- 収集範囲: Claude Code / Codex のローカルセッション686件、ユーザー発言2,310件（Claude 12セッション、Codex 674セッション）
- 分析単位: 1セッション。収集件数は対象範囲を示すだけで、好みの根拠件数ではない。
- 方法: 既存ログから、成果物や進め方への後続の指摘・修正を抽出。該当発言の前後にある依頼と応答を確認し、ユーザーが明示した内容と分析上の仮説を分けた。
- 根拠抜粋: [指摘と前後関係](prompts/2026-10-10-correction-observations.md)

## 初回の観察

### 依頼の意図・方向性を成果物に反映する

- 根拠: 2026-08-11、2026-08-17の2セッション。詳細は[抜粋](prompts/2026-10-10-correction-observations.md#意図と前提を反映する)を参照。
- ユーザーが明示したこと: 既存案が意図と逆向きで好みではないと伝え、望む方向を説明した。また、構成変更でmacOSのx86/ARMとHome Managerの影響が抜けていないかを指摘した。
- 観察: 依頼の文面を実装に置き換えるだけでなく、目的や既存環境の前提が成果物に反映されているかを重視している可能性がある。
- 判定: **有力な観察候補**。ただし2セッションの事例であり、常に複数案比較を求めているとは言えない。曖昧なときに目的・前提との整合を確認するための参考にとどめる。

### 大きな方針や作業範囲を自分で確認・調整できるようにする

- 根拠: 2026-10-06、2026-10-09の2セッション。詳細は[抜粋](prompts/2026-10-10-correction-observations.md#方針と作業範囲を確認する)を参照。
- ユーザーが明示したこと: 方針は適合表を見て自分で確定または修正したいと述べた。別件では不要と判断したテストの削除と、PRからの `.takt/` 除外を指示した。
- 観察: 影響範囲が大きい方針や不要な追加作業を、ユーザーが確認・調整できる形で提示することを好む可能性がある。
- 判定: **有力な観察候補**。ただし、確認の必要性は変更の影響や依頼の明確さによる。些細な判断まで毎回確認する根拠にはしない。

## まだ一般化しないこと

- PR作成や障害調査を何度も依頼していることは、タスクの種類の反復であり、成果物への好みを直接示さないため、この分析では好みの根拠にしていない。
- テスト不要という判断は2026-10-09の特定PRでの明示であり、他の作業でも検証を省きたいという恒常的な好みとは扱わない。
- 上記はCodexのログで確認した少数の事例。Claudeを含む共通傾向や全作業への適用は未確認。

## 作業時に使う場合の暫定メモ

過去の指摘から得た仮説として、依頼の目的・環境前提・変更範囲が成果物に反映されているかを確認する。方針が複数あり影響が大きい場合は、比較できる案や適合表を先に提示し、不要な追加作業は含めない。案件ごとの明示指示を優先し、仮説だけで確認を増やしたり作業を省略したりしない。

このメモはまだ02の確定知識や全作業共通のルールではない。異なる作業で同様の指摘が増えたら再評価する。
